# 一、技术交底书

## 1. 发明名称

一种基于阶段条件强化学习的无人挖掘机端到端控制方法及系统

---

## 2. 技术领域

本发明涉及工程机械自动化与智能控制领域，具体涉及一种用于挖掘机作业（平地、挖掘、装载等）的**端到端控制方法**，融合强化学习与模仿学习，实现**无需轨迹规划的直接控制策略生成**。

---

## 3. 背景技术

当前无人挖掘机系统普遍采用如下控制架构：

```
感知 → 轨迹规划 → 轨迹跟踪控制 → 液压执行
```

存在以下问题：

### （1）轨迹规划依赖强

* 需人工设计轨迹参数
* 难以适应复杂工况（不同土质、坡度）

### （2）液压系统非线性严重

* 强耦合（动臂/斗杆/铲斗）
* 存在明显延迟（100~300ms）

### （3）控制误差累积

* 轨迹规划误差 + 跟踪误差叠加

### （4）泛化能力差

* 不同工况需重新调参

---

## 4. 发明目的

本发明旨在提供一种：

* **无需轨迹规划层**
* **能够适应液压延迟**
* **具备强泛化能力**
* **适用于复杂工况**

的无人挖掘机控制方法。

```
                   ↓
    +------------------------------------+

    |  ├─ CNN图像编码 (Res50+FPN)        |
    |  ├─ 土方量估计网络                 |
    |  ├─ 压力间接获取模块               |
    |  └─ 工作质量评估器                 |
    +------------------------------------+
                   ↓
    +------------------------------------+
    |  约束检查模块 (安全层)              |

    |  └─ 作业范围限制                   |
    +------------------------------------+
                   ↓
    +------------------------------------+
    | 阶段条件策略网络                   |

```


通过：

* 历史状态序列
* RNN / Transformer

建模：

```
a_t = π(s_t, s_{t-1}, ..., s_{t-n})
```

## 5.3 状态空间设计（商用优化版）

状态向量分为**直接测量量**和**估计量**两类，总维度约150-200维。

### （1）机械状态（直接测量，维度：6）

* 三轴角度：θ_boom, θ_arm, θ_bucket
* 三轴角速度：dθ_boom/dt, dθ_arm/dt, dθ_bucket/dt

### （2）末端工作状态（计算得出，维度：4）

* 末端位置 (x, y, z)：通过正向运动学计算
* 末端速度模：|v_end| = ||dp/dt||

### （3）视觉特征（CNN编码，维度：128-256）**[关键创新]**

**原始输入**
* 摄像头：RGB彩色图或RGB-D深度图
* 分辨率：320×240（平衡实时性与精度）
* 帧率：20-30 Hz

**特征提取**
```
特征向量 f_img = CNN_encoder(image)
其中CNN_encoder = ResNet50 + FPN (特征金字塔网络)
输出维度：128-256
编码内容：
  - 土堆轮廓与高度分布
  - 铲斗装载状态
  - 作业面平整度信息
  - 周围障碍物检测
```

### （4）土方量估计（关键商用指标，维度：2）**[商用重点]**

```
当前装载量估计：
V_current = g_load(f_img, θ_bucket, depth_history)

累计挖方量：
V_total = ∑ V_i (第i个挖掘循环的装载量)

其中g_load是一个轻量级网络：
g_load(·) = MLP(图像特征 + 机械状态 + 历史深度变化)
```

### （5）压力状态间接获取（维度：3）**[专利创新点]**

不直接测量液压压力，通过以下信息间接估计：

```
压力估计 = f_pressure(u_t, dθ/dt, |Δu|, 历史负载)

具体机制：
  p_boom_est = w1·|u_boom| + w2·|dθ_boom/dt| + w3·V_current + b1
  p_arm_est  = w1·|u_arm|  + w2·|dθ_arm/dt|  + w3·V_current + b2
  p_bucket_est = w1·|u_bucket| + w2·|dθ_bucket/dt| + w3·V_current + b3

权重(w1,w2,w3,b)通过模仿学习或RL自动学习
物理直观性：
  - 手柄位置|u|越大→液压指令越强→压力越高
  - 角速度越大→负载约束越强→压力越高
  - 装载量V_current越大→负荷越重→压力越高
```

### （6）工作质量指标（维度：3）**[商用必需]**

```
平整度评估：
flatness = -√(∑(depth[i] - depth_mean)²) 
         计算自深度图的高度方差，越平整值越高

完成度评估：
completeness = V_accumulated / V_target 
            范围[0,1]，表示完成的百分比

稳定性指标：
smoothness = -∑|Δu_t| (历史10帧控制信号变化量)
         越平滑值越高，代表控制更稳定
```

### （7）初始位置与范围约束（维度：6）**[商用安全]**

```
作业前输入信息：
  p_init：初始挖臂位置 (x0, y0, z0)
  z_ground_init：初始工作面高度
  p_target：目标卸载位置 (x_t, y_t, z_t)
  safety_radius：安全作业半径
  depth_limit：最大挖掘深度

实时约束检查：
  相对位置 = 当前位置 - p_init
  违反判定：if ||相对位置|| > safety_radius → 触发约束
          if 深度 < -depth_limit → 触发约束
```

### （8）控制历史序列（维度：6n, n=10-20）**[建模延迟]**

```
历史控制输入：[u_{t-n}, u_{t-n+1}, ..., u_{t-1}, u_t]
历史手柄信号：[h_{t-n}, h_{t-n+1}, ..., h_{t-1}, h_t]

用途：通过LSTM隐式学习100-300ms的液压延迟特性
示意：u_t 的效果在 t + 100-300ms 时反映在状态中
      网络通过历史序列学习这种延迟映射
```

### （9）阶段信息（维度：3）**[关键条件]**

```
phase_vector = one-hot编码([复位阶段, 挖掘阶段, 卸载阶段])
  [1, 0, 0]：复位阶段（挖臂上升回位）
  [0, 1, 0]：挖掘阶段（向下挖进）
  [0, 0, 1]：卸载阶段（上升并转身)

用途：策略网络 π(s, phase) 根据不同阶段采取不同策略
```

### 完整状态向量（商用部署版）

```
s_t = [机械状态(6)
       末端工作状态(4)
       CNN图像特征(128-256)              ← 新增关键
       土方量估计(2)                      ← 新增关键
       压力间接估计(3)                    ← 新增关键
       工作质量指标(3)                    ← 新增关键
       初始位置相对量(6)                  ← 新增约束
       手柄位置(3)
       历史控制序列(3n, n=10-20)
       历史手柄序列(3n)
       阶段标志(3)
       ]
       
总维度：约 150-250

实际应用建议：
  - 图像特征维度：128维（轻量，实时性好）
  - 历史序列长度：n=15帧（150ms@100Hz）
  - 更新频率：20-100 Hz（根据控制延迟）
```

## 5.5 策略网络设计（商用推荐方案）

### 方案：LSTM + 视觉编码器（推荐商用）

```
多分支并行处理：

分支1：图像编码
  RGB/深度图 → ResNet50+FPN → f_img(128维)

分支2：时序建模
  [s_t, s_{t-1}, ..., s_{t-n}] → LSTM(256单元) → h_lstm(256维)

分支3：阶段条件
  phase_onehot(3维) → FC(32维) → f_phase(32维)

融合层：
  [f_img(128) + h_lstm(256) + f_phase(32)] 
  → FC(256) → ReLU → FC(128) → 输出动作(3维)
  → Tanh → [u_boom, u_arm, u_bucket]

总参数量：约50-100K（小于10MB）
推理延迟：<50ms@GPU或100ms@CPU
```

### 网络细节

```
LSTM层：
  - 输入维度：约160维（传感器+历史）
  - 隐层数：1-2层
  - 隐元数：256
  - Dropout：0.1（防止过拟合）
  - 目的：隐式建模100-300ms液压延迟

图像编码：
  - 预训练ResNet50（ImageNet）迁移学习
  - 去掉全连接层，取倒数第2层特征
  - FPN + Global Average Pooling
  - 目的：提取土堆形状、装载量、平整度等视觉特征

输出层：
  - Tanh激活（输出范围[-1,1]）
  - 无加噪（推理时确定性输出）
```

## 5.6 奖励函数设计（商用优化版）

### 总奖励函数

```
R_total = w_vol·R_volume + w_quality·R_quality + w_smooth·R_smooth 
        + w_time·R_time + w_safety·R_safety

推荐权重：
w_vol = 0.4    (土方量完成度，最重要)
w_quality = 0.3 (作业质量)
w_smooth = 0.15 (控制平滑性)
w_time = 0.1   (效率，不过度优化速度)
w_safety = 0.05 (安全约束，惩罚越界)
```

---

### 详细子奖励设计

#### （1）土方量完成度 **[商用核心指标]**

```
R_volume = {  
  -100            if V_accumulated < 0.5·V_target  (严重不足)
  -(V_target - V_accumulated)²  if 在范围内 (最小化偏差)
  -10·(V_accumulated - V_target)  if 过挖 (惩罚超量)
}

自适应目标：
若检测到一个完整循环，触发验证：
  if |V_cycle - V_target| < 5%:
    R_bonus = +50 (高完成度奖励)
  else:
    R_penalty = -20 (低完成度惩罚)
```

#### （2）工作质量奖励 **[差异化指标]**

```
按阶段分化：

挖掘阶段 (phase=1):
  R_quality = -(z_current - z_target)  如果还未到达目标深度
            + flatness_bonus            平整且深度合适时的正奖励

卸载阶段 (phase=2):
  R_quality = completeness·100          铲斗装载量占比
            - spillage_penalty          如有溅土扣分

复位阶段 (phase=0):
  R_quality = -|p_current - p_home|    回位精度奖励
```

#### （3）平滑性奖励 **[确保稳定]**

```
R_smooth = -λ·∑|Δu_t|  其中 λ=0.01
         = -λ·∑|u_t - u_{t-1}|

物理意义：
  - 控制信号变化越剧烈，扣分越多
  - 确保液压系统响应稳定，减少冲击
  - 典型值：<5帧内 Δu 控制在 0.1-0.2 范围
```

#### （4）时间效率 **[约束而非优先]**

```
R_time = -0.01·t  (轻微线性惩罚)

注意：
  - 不能为主要优化目标（会导致不安全加速）
  - 仅用作小的引导项
  - 若一个循环超过300秒，额外惩罚
```

#### （5）安全约束惩罚 **[硬约束]**

```
R_safety = {
  -1000  if 位置越界 (||p - p_init|| > safety_radius)
  -500   if 挖掘深度超限 (depth > depth_max)
  -300   if 估计压力饱和 (p_est > p_max_safe)
  -200   if 控制信号异常 (|u| > 1.2)
  0      if 安全
}

作用：作为硬约束，任何违规都会显著降低当前轨迹的奖励
```

### 奖励示例（典型循环）

```
场景：目标挖掘体积 V_target = 0.8 m³

情况1：高质量完成
  V_accumulated = 0.78 m³
  flatness_score = 85%
  smoothness = 高
  time = 120秒
  safety = 无越界
  
  R_vol ≈ -0.04 (很小的不足)
  R_quality ≈ +40 (高质量奖励)
  R_smooth ≈ -2
  R_time ≈ -1.2
  R_safety = 0
  ────────────
  R_total ≈ +36.76

情况2：低质量或不完全
  V_accumulated = 0.5 m³
  flatness_score = 50%
  
  R_vol ≈ -100 (严重不足，直接降分)
  R_quality ≈ -10
  R_safety = 0
  ────────────
  R_total ≈ -110 (反向学习避免此行为)
```

## 8. 商用部署保障与实现细节

### 8.1 初始位置与作业参数输入接口

```
系统启动流程：

1. 操作员输入初始信息（作业前一次性设置）：
   ├─ 初始臂端位置 p_init = (x0, y0, z0)
   ├─ 初始地面高度 z_ground_init
   ├─ 目标装载量 V_target (m³)
   ├─ 目标卸载位置 p_unload = (x_u, y_u, z_u)
   ├─ 安全作业半径 R_safety (相对p_init的约束)
   └─ 最大挖掘深度 d_max (相对z_ground_init)

2. 系统初始化：
   ├─ 校准传感器（编码器、IMU）
   ├─ 读取初始挖臂配置
   └─ 加载对应工况的预训练模型

3. 实时约束更新：
   ├─ 相对位置 = 当前位置 - p_init
   └─ 安全检查：||相对位置|| < R_safety and 深度 < d_max
```

### 8.2 图像处理与视觉反馈

```
摄像头配置：
  - 位置：安装在挖臂下端或斗杆侧面
  - 类型：工业RGB相机 或 RGB-D深度相机
  - 分辨率：320×240（每帧5-8ms处理时间）
  - 帧率：20-30Hz（与控制循环同步）

图像特征提取：
  1. 预处理：直方图均衡化、去畸变
  2. 特征提取：ResNet50编码器 (128维向量)
     包含信息：
     - 土堆高度分布（用于平整度评估）
     - 铲斗装载量视觉线索（铲斗张角、装载状态）
     - 作业面坡度信息
  3. 缓存：维护特征向量循环队列（最近10帧）
```

### 8.3 土方量估计模块

```
实现方案（混合视觉+机械）：

输入：
  - 图像特征 f_img (128维)
  - 铲斗角度 θ_bucket 和角速度
  - 历史深度变化 Δz_{t-n..t}
  - 铲斗标准容积 V_bucket_std (已知参数)

估计网络（轻量MLP）：
  V_est = MLP(f_img, θ_bucket, dθ_bucket/dt, 历史深度)
  
  具体实现：
    输入层 → FC(64) → ReLU → FC(32) → ReLU 
           → FC(1) → Sigmoid × V_bucket_std
  
  输出范围：[0, V_bucket_std]

校准与优化：
  - 第一个循环后：用实际装载量反馈微调权重
  - 通过人工反馈或称重传感器校准
  - 累计误差 < 5% 为可接受

累计体积计算：
  V_accumulated = ∑ V_current (每完成一个循环计数一次)
```

### 8.4 液压压力间接获取算法

```
核心创新：无压力传感器的压力估计

基本原理：
  液压压力 与以下因素正相关：
  1. 手柄指令强度 |u|（指令越强，液压供给越大）
  2. 负载（表现为角速度降低、力矩增大）
  3. 装载量（V_current增大时负荷增加）

估计公式：
  p_est = f(|u|, |dθ/dt|, V_current, 历史状态)
  
  线性近似（初步）：
    p_boom = α·|u_boom| + β·|dθ_boom/dt| + γ·V_current + δ·max_load
    
  其中参数(α,β,γ,δ)通过：
    - 模仿学习：从专家数据（含压力传感）中学习
    - 或RL学习：最小化压力超限触发约束的频率

非线性拟合（更精确）：
  可用小型神经网络：
    [|u|, |dθ/dt|, V, history(10维)] → MLP → p_est
    参数量 < 1000，推理 < 1ms

验证机制：
  - 当等速阶段：压力应稳定在某个范围
  - 当加速/减速：压力波动应与指令同步
  - 异常判定：若p_est高频震荡 → 警告
```

### 8.5 约束检查与安全保障（硬约束层）

```
约束检查在每个控制周期执行（单独线程）：

1. 几何约束：
   ├─ 作业半径约束
   │  if ||p_current - p_init|| > R_safety:
   │     u_out = clip(u_policy, 远离边界方向)
   │
   ├─ 深度约束
   │  if depth < -d_max:
   │     u_boom = max(0, u_policy_boom)  # 禁止继续下挖
   │
   └─ 关节极限
      if θ_i > θ_max or θ_i < θ_min:
         u_i = clip(u_policy_i, 合法范围)

2. 液压约束：
   ├─ 压力极限检查
   │  if p_est > p_max_safe (通常 p_max × 0.9):
   │     λ = (p_max - p_est) / p_max  # 衰减因子
   │     u_out = λ × u_policy
   │
   └─ 流量限制
      if sum(|u_i|) > Q_max:
         u_out = u_policy × (Q_max / sum(|u_i|))

3. 安全状态监控：
   ├─ 若触发任意硬约束 → 记录日志并警告
   ├─ 若频繁触发 → 调整目标参数或切换手动模式
   └─ 紧急停止：任何异常 → 全轴清零

修正后输出：
  u_final = 约束_修正(u_policy, 当前约束状态)
```

### 8.6 控制延迟的隐式处理

```
液压系统特性：
  真实响应 = 延迟(100-300ms) + 非线性阻尼

解决方案：时序建模

LSTM学习延迟映射：
  状态序列 s_{t-n:t} (历史15帧@100Hz = 150ms)
         ↓
       LSTM(256单元，1-2层)
         ↓
  隐状态 h_t (包含延迟信息)
         ↓
  策略输出 u_t = π(h_t, phase)

学习机制：
  - IL阶段：LSTM对人工操作的延迟演变进行拟合
  - RL阶段：SAC/PPO自动优化对延迟的补偿
  
  结果：网络在 t 时刻生成的动作 u_t，
       会在 t+150ms 时使实际状态达到预期值
       
典型表现：
  - 闭环控制：延迟被隐式补偿，等效响应延迟 < 100ms
  - 动作平滑性：通过奖励函数 R_smooth 约束
```

```

(6) 策略推理：
    (6.1) 状态序列[s_{t-n}, ..., s_t]输入LSTM，获得时序隐状态；
    (6.2) 将隐状态与phase结合，通过策略网络输出原始控制指令u_π；
(7) 约束修正：对u_π进行硬约束检查与修正，生成最终控制信号u_final；
(8) 执行与反馈：驱动液压系统，记录作业效果（土方量、质量等）；
(9) 可选：收集真实数据，微调网络参数或压力估计权重。

其特征在于：
  - (3.2)和(3.3)无需额外硬件传感器；
  - (6)的LSTM隐式建模100-300ms的控制延迟；
  - (7)的硬约束保证安全性，无需依赖奖励函数的软约束；
  - 整个流程端到端运行，无轨迹规划中间层。
```
