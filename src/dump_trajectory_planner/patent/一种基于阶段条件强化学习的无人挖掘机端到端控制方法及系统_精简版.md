# 一种面向液压挖掘机循环作业的阶段条件端到端控制方法及系统

## 一、技术交底书

### 1. 发明名称

一种面向液压挖掘机循环作业的阶段条件端到端控制方法及系统

---

### 2. 技术领域

本发明涉及工程机械自动化、液压执行系统控制和智能控制领域，具体涉及一种用于液压挖掘机循环作业的控制方法及系统。该方法根据挖掘机的作业阶段、当前状态和历史状态序列，直接生成动臂、斗杆和铲斗等执行机构的控制指令，并通过约束修正模块提高控制输出的可执行性和安全性。

---

### 3. 背景技术

现有无人挖掘机或自动挖掘控制系统通常采用如下结构：

```text
环境感知 -> 作业规划/轨迹规划 -> 轨迹跟踪控制 -> 液压执行
```

该类方案在规则明确、环境稳定的场景中较容易实现，但在真实挖掘作业中仍存在以下问题：

1. 液压执行系统存在非线性、迟滞和多执行机构耦合，轨迹跟踪控制难以准确反映实际响应。
2. 挖掘过程与土壤接触强相关，土质、含水量、堆积形态和负载变化会导致规划轨迹与实际可执行动作之间存在偏差。
3. 轨迹规划误差、状态估计误差和跟踪误差可能在控制链路中叠加。
4. 挖掘作业通常包含复位、挖掘、提升、卸载等不同阶段，不同阶段的目标和约束并不相同，单一控制策略难以同时兼顾各阶段要求。

因此，需要一种能够面向液压挖掘机循环作业特点，利用阶段信息和历史时序信息生成控制指令，并在输出端进行安全约束修正的控制方法。

---

### 4. 发明目的

本发明的目的在于提供一种面向液压挖掘机循环作业的阶段条件端到端控制方法及系统，以解决或缓解以下问题：

1. 降低对显式轨迹规划中间层的依赖；
2. 利用历史状态和历史控制信息适应液压系统的迟滞、延迟和耦合特性；
3. 根据不同作业阶段生成具有针对性的控制指令；
4. 在非固定作业场景中根据作业面环境表示和满斗率估计调整挖掘动作，提高单斗装载稳定性；
5. 在学习型策略输出之后设置约束修正模块，使最终控制指令满足作业范围、关节极限、执行机构能力和安全规则等要求；
6. 支持通过人工示教数据、仿真数据和实机数据对策略模型进行训练或更新。

---

### 5. 技术方案

#### 5.1 总体架构

系统可包括如下模块：

```text
作业参数输入模块
        |
环境感知与机械状态采集模块
        |
状态估计与特征构建模块
        |
作业面表示与满斗率估计模块
        |
作业阶段管理模块
        |
阶段条件策略模块
        |
约束修正模块
        |
液压执行控制模块
```

其中，作业参数输入模块用于输入或读取作业区域、初始位置、目标卸载位置、目标作业量、最大作业深度或安全边界等参数。环境感知与机械状态采集模块用于获取关节角度、角速度、位姿、手柄或阀控信号、图像、深度图、点云或地图信息等。状态估计与特征构建模块用于形成策略模型所需的状态向量。作业面表示与满斗率估计模块用于生成挖掘前方区域的环境表示，并估计当前装载量或满斗率。作业阶段管理模块用于根据有限状态机、行为树、规则条件或其组合确定当前处于复位阶段、挖掘阶段、卸载阶段或其他预设阶段。阶段条件策略模块根据状态、阶段信息和满斗率估计结果调用对应阶段策略或条件化策略，输出原始控制指令。约束修正模块对原始控制指令进行限幅、方向限制、平滑或降级处理后，输出至液压执行控制模块。

本方案中的“端到端控制”是指策略模块可由状态特征直接生成执行控制量，而不需要先生成铲斗或臂架的连续轨迹再进行轨迹跟踪。系统仍可保留作业目标点、安全边界、阶段切换规则等高层约束信息。

---

#### 5.2 核心技术特征

##### 5.2.1 阶段条件策略

将挖掘机循环作业划分为多个阶段，例如：

```text
phase ∈ {复位阶段, 挖掘阶段, 卸载阶段}
```

也可根据具体作业需求扩展为：

```text
phase ∈ {复位, 入土, 挖掘, 提升, 回转, 卸载}
```

当前作业阶段可由阶段管理模块给定。阶段管理模块可采用有限状态机、行为树、规则引擎或其组合，根据机械状态、末端位置、铲斗装载状态、目标点到达状态、作业量估计、安全状态和人工接管状态等条件确定阶段并触发阶段切换。

有限状态机适用于固定循环作业，例如：

```text
复位 -> 挖掘 -> 提升/回转 -> 卸载 -> 复位
```

行为树适用于包含异常处理和优先级判断的自动作业，例如：

```text
Selector
  - 安全停止/人工接管
  - 异常恢复
  - 自动作业序列：复位、挖掘、提升、回转、卸载
```

阶段确定后，系统可采用以下任一种方式生成控制指令：

1. 调用与当前阶段对应的独立阶段策略模型，例如 `π_reset`、`π_dig`、`π_dump`；
2. 调用共享特征编码器和当前阶段对应的输出头；
3. 将当前阶段以 one-hot 向量、枚举编码或连续嵌入向量的形式输入统一策略模型。

当采用统一策略模型时，策略模型根据状态和阶段联合生成控制指令：

```text
u_raw = π(s_t, phase_t)
```

其中，`s_t` 为当前状态或包含历史信息的状态表示，`phase_t` 为当前作业阶段，`u_raw` 为原始控制指令。

该设计将“何时切换阶段”与“当前阶段如何控制”分离：阶段管理模块负责阶段切换和异常优先级，策略模型负责在当前阶段内生成具体控制指令。不同作业阶段可以共享感知和状态表示，也可以采用独立阶段模型，以降低不同阶段控制目标相互干扰的风险。

##### 5.2.2 基于历史序列的液压响应建模

液压挖掘机的执行机构响应通常受阀控特性、油液温度、负载变化、复合动作和机械结构影响，表现为迟滞、延迟和非线性耦合。为适应该特性，本方案将历史状态、历史动作或二者的组合输入时序模型：

```text
H_t = {s_{t-n}, ..., s_t, u_{t-n}, ..., u_{t-1}}
```

并通过循环神经网络、门控循环单元、长短期记忆网络、时序卷积网络或 Transformer 等时序模型生成隐状态：

```text
h_t = F_temporal(H_t)
```

策略模型再根据 `h_t` 和 `phase_t` 输出控制指令：

```text
u_raw = π(h_t, phase_t)
```

历史窗口长度、采样频率和时序模型结构可根据具体机型、控制周期和传感器配置设定。

##### 5.2.3 直接控制指令生成

策略模型输出可对应一个或多个液压执行机构的控制量，例如：

```text
u_raw = [u_boom, u_arm, u_bucket]
```

其中，`u_boom`、`u_arm` 和 `u_bucket` 分别对应动臂、斗杆和铲斗的控制指令。根据设备配置，输出也可扩展至回转、行走、属具或其他液压执行机构。

控制指令可以是归一化手柄量、阀控电流、阀芯位移指令、速度设定值或经底层控制器转换后的等效控制量。

##### 5.2.4 约束修正与安全保护

学习型策略输出的原始控制指令不直接作为最终执行指令，而是经过约束修正模块处理：

```text
u_final = C(u_raw, s_t, phase_t, constraints)
```

约束可包括：

1. 作业区域约束：限制末端、铲斗或机身进入禁止区域；
2. 深度约束：限制铲斗继续向超过预设深度的方向运动；
3. 关节约束：限制各关节角度、角速度或加速度超过机械允许范围；
4. 执行机构约束：限制阀控信号、泵流量或复合动作总需求超过设备能力；
5. 平滑约束：限制相邻控制周期内控制量变化过大；
6. 安全降级约束：在传感器异常、模型输出异常或人工接管时进入降级或停止状态。

约束修正方式可包括限幅、投影、方向抑制、比例缩放、滤波、规则覆盖或切换至传统控制器。

##### 5.2.5 面向非固定场景的作业面感知与满斗率估计

在非固定作业场景中，土堆形态、作业面高度、入土位置和剩余可挖土量会随循环不断变化。若系统需要稳定控制铲斗满斗率，仅依赖机械状态和历史控制通常不足以判断“当前应从哪里挖、挖多深、是否已经装满”。因此，在用于非固定场景或需要稳定满斗率的实施例中，系统优选引入作业面环境表示或载荷反馈。

作业面环境表示可包括以下一种或多种：

1. 挖掘前方区域的 RGB 图像、深度图或点云；
2. 局部高度图、占据栅格、数字高程图或局部地形地图；
3. 由多帧感知数据融合得到的待挖区域形态、已挖区域变化和剩余土方量；
4. 铲斗相对作业面的位姿、入土深度、切削路径和目标挖掘区域。

系统可根据作业面环境表示、铲斗几何参数、铲斗姿态、历史深度变化、液压负载或称重信息估计当前装载量和满斗率：

```text
fill_ratio = V_bucket_current / V_bucket_capacity
```

其中，`V_bucket_current` 表示估计的当前铲斗装载量，`V_bucket_capacity` 表示铲斗标称容量或修正后的有效容量。满斗率估计结果可用于挖掘阶段策略输入、阶段切换条件、奖励或评价指标。

在不具备视觉、深度、地图或载荷反馈的实施例中，系统仍可根据铲斗几何、入土深度、切削长度、循环次数和历史经验估计装载量，但该方式更适用于固定或弱变化场景，不宜作为非固定场景下稳定满斗率的唯一依据。

##### 5.2.6 满斗率稳定控制闭环

为提高非固定场景下的满斗率稳定性，系统可建立如下闭环：

```text
作业面环境表示/载荷反馈
        ↓
满斗率估计 fill_ratio
        ↓
FSM/BT 阶段切换与挖掘策略输入
        ↓
阶段策略输出控制指令
        ↓
约束修正与执行
        ↓
更新作业面地图和装载状态
```

在挖掘阶段，阶段策略可根据当前作业面高度、可挖土量、铲斗姿态、历史控制和当前满斗率估计，调整入土角度、切削深度、斗杆回收速度和铲斗收斗时机。阶段管理模块可根据满斗率阈值、目标深度、切削路径完成度或液压负载变化判断是否从挖掘阶段切换至提升或卸载阶段。

典型切换条件可包括：

1. `fill_ratio` 达到目标区间；
2. 铲斗到达目标切削终点或目标深度；
3. 液压负载或压力风险持续升高，表明继续挖掘收益下降或存在过载风险；
4. 作业面地图显示当前区域剩余可挖土量不足，需要更换入土点；
5. 安全约束触发，需要提前结束当前挖掘动作。

##### 5.2.7 可选的液压负载或压力风险估计

在未配置压力传感器、压力信号不可用或需要冗余判断的实施例中，系统可根据控制指令、关节运动响应、铲斗装载状态、执行机构速度变化或历史负载特征，估计液压负载状态或压力风险指标：

```text
r_pressure = f(u, dθ/dt, Δu, load_feature, history)
```

该指标可用于判断是否需要降低控制幅值、限制复合动作或触发安全降级。该估计不必替代真实压力传感器；在具备压力传感器的设备上，也可与压力传感器信号共同用于冗余校验。

### 6. 状态空间设计

状态向量可由以下信息中的一种或多种组成：

1. 机械状态：动臂、斗杆、铲斗等关节角度、角速度、角加速度；
2. 末端状态：铲斗或工作装置末端位置、速度、姿态；
3. 控制历史：历史手柄量、阀控指令或策略输出；
4. 作业参数：初始位置、目标卸载位置、作业边界、目标作业量、最大挖掘深度；
5. 阶段信息：当前阶段编码、阶段持续时间、阶段切换条件；
6. 环境特征：图像特征、深度特征、点云、局部高度图、占据栅格、作业面高度、障碍物或土堆形态；
7. 满斗率与作业质量特征：当前装载量估计、满斗率、累计作业量、平整度或完成度；
8. 设备状态：油温、泵状态、压力信号、估计负载或故障状态。

状态维度、特征类型和采样频率不作固定限定，可根据传感器配置和控制器算力进行选择。

在用于非固定场景且要求满斗率稳定的实施例中，状态表示优选包括作业面环境表示和满斗率估计结果。作业面环境表示可由车载相机、深度相机、激光雷达、外部测量设备或施工地图生成，也可由多次挖掘前后的地形变化融合得到。

### 7. 策略模型设计

策略模型可采用统一条件模型、独立阶段模型或共享主干多输出头模型。

统一条件模型结构可表示为：

```text
机械/控制历史分支 -> 时序编码器
视觉或环境分支   -> 特征编码器
阶段信息分支     -> 阶段嵌入
                  |
              特征融合层
                  |
              控制输出层
```

独立阶段模型结构可表示为：

```text
阶段管理模块输出 phase_t
        |
        |-- 复位阶段 -> π_reset(s, history)
        |-- 挖掘阶段 -> π_dig(s, history)
        |-- 卸载阶段 -> π_dump(s, history)
```

共享主干多输出头结构可表示为：

```text
shared_encoder(s, history)
        |
        |-- reset_head
        |-- dig_head
        |-- dump_head
```

其中，时序编码器可采用 LSTM、GRU、TCN 或 Transformer；视觉编码器可采用 CNN、轻量化 CNN、深度图编码器或多模态编码器；阶段信息可采用 one-hot 编码、嵌入向量、门控参数、阶段模型索引或输出头选择信号。

策略输出层可使用限幅函数或归一化函数，将输出控制量限制在预设范围内。最终输出仍需经过约束修正模块。

### 8. 训练方式

本发明不限定策略模型只能通过某一种训练方式获得。可选训练方式包括：

1. 模仿学习：利用人工操作数据训练策略模型，使其拟合专家操作；
2. 离线强化学习：利用历史数据和作业评价指标优化策略；
3. 仿真强化学习：在仿真环境中训练或微调策略；
4. 监督学习：针对阶段切换条件、装载量估计、满斗率估计、风险估计等子模块进行训练；
5. 混合训练：先通过模仿学习获得初始策略，再通过仿真或离线数据进行优化。

对于非固定场景下的满斗率稳定控制，训练数据优选包含挖掘前方区域的图像、深度图、点云、高度图、占据栅格或局部地形地图中的至少一种，并包含对应的铲斗位姿、控制指令、装载量标签或满斗率标签。满斗率标签可来自称重系统、压力/载荷估计、卸载后体积测量、人工标注、仿真环境真实值或多源融合估计。

在实机部署阶段，可优先采用受约束的模型更新、人工复核后的离线更新或小范围参数适配，避免未经约束的实机探索。

---

### 9. 奖励与评价指标

当采用强化学习或离线强化学习训练时，奖励或评价指标可包括：

1. 满斗率与作业量指标：单斗满斗率、满斗率稳定性、装载量、累计挖方量、目标完成度；
2. 作业质量指标：平整度、残留量、溢洒情况、目标位置偏差；
3. 控制平稳性指标：控制量变化率、冲击、振荡；
4. 效率指标：单循环时间、单位时间作业量；
5. 安全指标：越界、超深、关节极限、执行机构饱和、人工接管次数。

满斗率稳定性可通过目标区间偏差或多循环方差进行评价，例如鼓励 `fill_ratio` 落入预设目标区间，并惩罚明显欠装、过载、溢洒或因过度追求满斗导致的执行机构饱和。上述指标的权重可根据作业类型、机型和现场安全要求设定。安全相关指标既可用于训练惩罚，也应在部署时通过约束修正模块独立执行。

### 10. 具体实施方式

#### 实施例一：基于人工示教的阶段条件控制

1. 采集人工操作过程中的机械状态、手柄信号和作业阶段标签；
2. 构建包含当前状态、历史控制和阶段编码的训练样本；
3. 使用模仿学习训练策略模型，使其输出接近人工操作指令；
4. 部署时由策略模型输出原始控制指令，再经约束修正模块得到最终控制指令。

该实施例适用于固定作业区域、固定卸载点或受限场景下的自动循环作业。

#### 实施例二：基于有限状态机或行为树的阶段管理

1. 预设作业阶段及其切换条件，例如复位完成、铲斗到达挖掘起点、装载状态达到阈值、到达卸载位置或卸载完成；
2. 通过有限状态机或行为树根据当前状态和切换条件输出当前阶段；
3. 在当前阶段内调用对应阶段策略模型，或选择共享模型的对应输出头；
4. 当检测到越界、传感器异常、人工接管或执行机构饱和时，行为树优先执行安全停止、异常恢复或降级控制节点；
5. 阶段策略输出的原始控制指令经约束修正模块处理后执行。

该实施例适用于需要明确阶段切换逻辑、异常优先级和人工接管机制的自动作业系统。

#### 实施例三：基于历史序列的液压延迟补偿

1. 在状态中加入过去若干控制周期的状态和控制指令；
2. 使用 LSTM、GRU、TCN 或 Transformer 编码历史序列；
3. 将时序隐状态与当前阶段编码融合；
4. 输出动臂、斗杆和铲斗的控制指令；
5. 通过控制平滑和执行机构约束降低输出突变。

该实施例用于适应液压执行系统中随负载变化的迟滞和响应延迟。

#### 实施例四：非固定场景下的满斗率稳定控制

1. 通过摄像头、深度相机、激光雷达、外部测量设备或施工地图获取挖掘前方区域信息；
2. 生成局部高度图、占据栅格、点云特征或作业面地图，用于表征待挖区域形态和剩余可挖土量；
3. 结合铲斗几何、铲斗姿态、历史深度变化、称重信息或液压负载估计当前装载量和满斗率；
4. 将作业面地图和满斗率估计结果输入挖掘阶段策略模型；
5. 挖掘阶段策略根据当前作业面形态和满斗率估计调整入土点、切削深度、斗杆回收速度和收斗时机；
6. 阶段管理模块根据满斗率阈值、切削路径完成度、目标深度或负载风险判断是否切换至提升或卸载阶段；
7. 在环境感知信号不可用或质量较差时，系统可切换至保守挖掘策略、人工接管或仅适用于固定场景的降级模式。

该实施例适用于土堆形态和作业面位置随循环变化、且需要提高单斗满斗率稳定性的作业场景。

#### 实施例五：带有安全降级的约束修正控制

1. 策略模型输出原始控制指令；
2. 约束修正模块检查作业边界、深度、关节极限、执行机构能力和传感器状态；
3. 若控制指令满足约束，则输出平滑后的控制指令；
4. 若控制指令违反约束，则进行限幅、方向抑制或比例缩放；
5. 若检测到严重异常，则切换至安全停止、人工接管或传统控制器。

该实施例强调学习型策略与确定性安全规则的组合。

### 11. 有益效果

与依赖显式轨迹规划和轨迹跟踪的方案相比，本发明至少具有以下有益效果：

1. 通过阶段条件输入，使策略模型能够根据复位、挖掘、卸载等不同作业阶段生成不同控制行为；
2. 通过历史状态和历史控制序列，使模型能够利用过去的执行响应信息适应液压系统迟滞和耦合特性；
3. 通过从状态特征直接生成控制指令，减少显式轨迹规划与轨迹跟踪之间的中间误差传递；
4. 通过约束修正模块，使学习型策略输出受到作业边界、机械极限和执行机构能力限制；
5. 通过作业面环境表示和满斗率估计，使系统能够在非固定场景中根据土堆形态和装载状态调整挖掘动作；
6. 通过可选的视觉、地图、作业量估计和负载风险估计，支持更丰富的作业评价和阶段切换。

上述效果与具体机型、传感器配置、训练数据和现场环境有关，不限定为固定精度、固定延迟或固定性能指标。

以下内容适合作为内部研发计划或商业方案，不建议作为说明书中的强限定或绝对承诺：

6. 过细的商业部署周期、融资表述或产品承诺。

## 二、权利要求书初稿方向

### 权利要求1：系统权利要求

一种面向液压挖掘机循环作业的阶段条件端到端控制系统，其特征在于，包括：

1. 作业参数输入模块，用于获取作业区域、初始位置、目标卸载位置、作业边界或目标作业量中的至少一种；
2. 状态采集模块，用于获取液压挖掘机的机械状态、控制历史和环境状态中的至少一种；
3. 状态构建模块，用于根据所述机械状态、控制历史、环境状态和作业参数构建当前状态表示；
4. 作业面表示模块，用于根据图像、深度图、点云、高度图、占据栅格或局部地形地图中的至少一种生成挖掘前方区域的环境表示；
5. 满斗率估计模块，用于根据所述环境表示、铲斗几何、铲斗姿态、历史深度变化、称重信息或液压负载中的至少一种估计当前装载量或满斗率；
6. 阶段管理模块，用于根据有限状态机、行为树、规则条件或其组合确定当前作业阶段，所述作业阶段至少包括复位阶段、挖掘阶段和卸载阶段中的两个；
7. 阶段条件策略模块，用于根据当前状态表示、当前作业阶段和满斗率估计结果，调用对应阶段策略模型、选择对应阶段输出头或将当前作业阶段作为条件输入统一策略模型，以生成至少一个液压执行机构的原始控制指令；
8. 约束修正模块，用于根据作业边界、关节极限、执行机构能力或安全状态，对所述原始控制指令进行修正，得到最终控制指令；
9. 执行控制模块，用于根据所述最终控制指令驱动液压执行机构。

其中，所述阶段管理模块负责作业阶段切换，所述阶段条件策略模块负责当前作业阶段内的控制指令生成，并且根据当前状态表示直接生成液压执行机构控制指令，而不以连续轨迹跟踪作为必要中间步骤。

### 权利要求2：方法权利要求

一种面向液压挖掘机循环作业的阶段条件端到端控制方法，其特征在于，包括：

1. 获取作业参数和液压挖掘机的当前机械状态；
2. 获取历史状态序列和历史控制序列中的至少一种；
3. 获取或生成挖掘前方区域的图像、深度图、点云、高度图、占据栅格或局部地形地图中的至少一种；
4. 根据所述当前机械状态、历史状态序列、历史控制序列、作业参数和挖掘前方区域环境表示构建状态表示；
5. 根据所述环境表示、铲斗几何、铲斗姿态、历史深度变化、称重信息或液压负载中的至少一种估计当前装载量或满斗率；
6. 通过有限状态机、行为树、规则条件或其组合确定当前作业阶段；
7. 根据当前作业阶段、状态表示和满斗率估计结果调用对应阶段策略模型、选择对应阶段输出头或将当前作业阶段作为条件输入统一策略模型，生成原始控制指令；
8. 对所述原始控制指令进行约束修正，得到最终控制指令；
9. 根据所述最终控制指令驱动液压执行机构。

其中，所述阶段条件策略模型利用历史状态序列或历史控制序列表征液压执行机构的迟滞、延迟或耦合响应。

### 权利要求3：从属权利要求方向

可进一步限定：

1. 所述阶段条件策略模型包括 LSTM、GRU、TCN 或 Transformer 中的至少一种时序编码器；
2. 所述阶段管理模块包括有限状态机、行为树、规则引擎或其组合；
3. 所述有限状态机或行为树根据末端位置、铲斗装载状态、目标点到达状态、安全状态或人工接管状态中的至少一种触发阶段切换；
4. 所述当前作业阶段以 one-hot 编码、嵌入向量、门控参数、阶段模型索引或输出头选择信号形式作用于策略模型；
5. 所述阶段条件策略模块包括多个独立阶段策略模型、共享编码器与多个阶段输出头，或统一阶段条件策略模型；
6. 所述状态表示包括动臂、斗杆、铲斗的角度、角速度、历史控制指令、作业面环境表示和满斗率估计结果；
7. 所述作业面环境表示包括图像特征、深度图、点云、局部高度图、占据栅格或局部地形地图中的至少一种；
8. 所述满斗率估计模块根据铲斗标称容量和当前装载量估计满斗率；
9. 所述阶段管理模块根据满斗率阈值、目标深度、切削路径完成度、液压负载或作业面剩余可挖土量中的至少一种触发由挖掘阶段向提升或卸载阶段的切换；
10. 所述挖掘阶段策略模型根据作业面环境表示和满斗率估计结果调整入土点、切削深度、斗杆回收速度或收斗时机；
11. 所述约束修正包括控制限幅、方向抑制、比例缩放、滤波或安全降级；
12. 所述系统还包括液压负载或压力风险估计模块，用于根据控制指令和运动响应估计执行机构负载状态；
13. 所述策略模型通过模仿学习、离线强化学习、仿真强化学习或其组合训练获得；
14. 所述约束修正模块在检测到传感器异常、越界、超深或执行机构饱和时触发安全降级。

## 三、后续完善建议

### 1. 专利文本层面

1. 将“强化学习”作为训练方式之一，不作为唯一限定；
2. 将“无轨迹规划”改为“不以显式连续轨迹规划和轨迹跟踪作为必要中间步骤”；
3. 将“压力估计”改为“液压负载或压力风险估计”，避免被要求证明完全替代压力传感器；
4. 若主张非固定场景下满斗率稳定性，应将作业面环境表示和满斗率估计写入主权利要求或核心实施例；
5. 将压力风险估计、具体视觉模型和具体传感器型号放入从属权利要求或优选实施例；
6. 删除未经核实的竞品专利相似度评分，另行保留在内部检索报告中。

### 2. 工程验证层面

建议优先验证以下非固定场景满斗率闭环：

1. 使用深度相机、激光雷达、外部测量或局部地形地图获取挖掘前方区域表示；
2. 将作业面环境表示、机械状态、历史控制和阶段编码作为策略输入；
3. 建立装载量或满斗率标签，可来自称重、压力/载荷估计、仿真真实值或卸载后体积测量；
4. 通过人工示教或离线数据训练挖掘阶段策略，使其学习入土点、切削深度和收斗时机；
5. 用 FSM/BT 根据满斗率阈值、切削完成度和安全状态进行阶段切换；
6. 通过硬约束层限制越界、超深、过载和控制突变。

如果不引入环境表示或载荷反馈，系统仍可验证固定场景自动循环作业，但不宜将其作为非固定场景满斗率稳定性的主要实施例。

### 3. 商业落地层面

更现实的落地路径是：

1. 先做带环境感知的固定料堆或半固定料堆满斗率闭环；
2. 再做安全约束下的非固定作业面自动挖掘循环；
3. 后续扩展至不同土质、不同机型和复杂作业区域；
4. 始终保留人工接管、安全停止和传统控制器兜底机制。
