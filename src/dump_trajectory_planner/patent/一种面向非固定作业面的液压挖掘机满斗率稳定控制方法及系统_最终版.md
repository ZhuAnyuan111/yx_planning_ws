# 一种液压挖掘机满斗率阶段条件控制方法及系统

## 技术领域

本发明涉及工程机械自动化和智能控制技术领域，具体涉及一种用于液压挖掘机自动挖掘作业的控制方法及系统，尤其适用于土堆形态、作业面高度和剩余可挖土量随挖掘循环动态变化的非固定作业场景。

## 背景技术

液压挖掘机自动作业通常包含复位、入土、挖掘、提升、回转和卸载等阶段。现有自动控制方案普遍采用"环境感知→轨迹规划→轨迹跟踪→液压执行"的四层架构。该架构以轨迹规划为控制核心——先在工作空间中生成一条连续轨迹，再通过伺服控制跟踪该轨迹。

此类轨迹中心方案在固定作业点和规则场景下具有一定可行性，但在非固定作业场景中存在以下固有不足：

1. 土堆形态随每次挖掘循环变化，预先规划的轨迹与实际情况严重偏离，固定轨迹难以持续保证铲斗装载量的稳定性；
2. 液压系统存在迟滞、延迟以及动臂、斗杆、铲斗多执行机构之间的运动耦合，轨迹跟踪误差在液压执行环节容易被放大；
3. 挖掘、提升和卸载各阶段的控制目标不同——挖掘阶段追求装载效率，提升阶段追求平稳避障，卸载阶段追求快速彻底——单一控制策略或单一轨迹难以兼顾；
4. 轨迹类方案在中途完全依赖位置伺服跟踪，缺乏作业面形态和铲斗装载状态的实时反馈，一旦发生偏差无法在线修正；
5. 基于学习的端到端控制策略若直接输出执行指令，仍需要确定性安全约束进行修正。

因此，亟需一种全新控制架构，弱化对显式轨迹的依赖，将控制重心从"如何跟踪预设路径"转向"如何根据当前装载状态和作业面情况做出实时决策"。

## 发明内容

### 要解决的技术问题

本发明提供一种液压挖掘机满斗率阶段条件控制方法及系统，重点解决以下四个技术问题：

1. 非固定作业面下单斗满斗率不稳定的问题——使控制策略能够根据作业面变化和装载状态反馈实时调整挖掘动作；
2. 液压系统迟滞、延迟和复合动作耦合导致的控制偏差问题——建立历史序列与当前状态的关联模型；
3. 不同作业阶段控制目标差异导致的策略混杂问题——将阶段切换与阶段内控制解耦，各阶段独立优化；
4. 学习型策略输出缺乏安全约束的问题——在策略输出与液压执行之间增加确定性约束修正层。

### 技术方案

本发明的核心创新在于：**以阶段条件控制替代连续轨迹规划**。具体而言，系统不以轨迹规划和轨迹跟踪为必要中间步骤，而是通过有限状态机（FSM）和行为树（BT）管理作业阶段切换，各阶段调用独立的策略模型，根据作业面环境表示、满斗率估计结果和机械状态特征直接生成液压控制量。轨迹信息仅作为辅助约束或参考输入，而非必要中间层。

系统整体流程为：

```
作业面环境表示 → 满斗率估计 → 阶段管理（FSM/BT） → 阶段策略模型 → 约束修正 → 液压执行
```

这一架构的本质区别在于：传统方案先规划"路径"再控制"跟随"，本发明则直接根据"状态"决定"动作"。

#### 系统模块构成

系统由八个模块组成：

1. **作业参数输入模块**：输入作业边界、目标卸载点和目标满斗率区间；
2. **作业面感知与环境表示模块**：获取挖掘前方区域的环境信息并生成作业面环境表示；
3. **机械状态与历史控制采集模块**：获取动臂、斗杆、铲斗的实时状态及历史控制指令；
4. **满斗率估计模块**：根据视觉传感、压力传感或二者融合，估计当前铲斗装载量或判断装载状态；
5. **作业阶段管理模块**：通过FSM/BT确定并切换当前作业阶段；
6. **阶段条件策略模块**：根据当前阶段调用对应的策略模型，输出动臂、斗杆、铲斗的原始控制指令；
7. **约束修正模块**：对原始控制指令进行安全约束修正；
8. **液压执行控制模块**：根据修正后的控制指令驱动液压执行机构。

#### 作业面环境表示

系统获取挖掘前方区域的环境信息并形成作业面环境表示，用于描述待挖区域形态、已挖区域变化和剩余可挖土量。可采用深度图、RGB-D图像、点云、局部高度图、占据栅格或局部地形地图中的至少一种。优选采用局部高度图或占据栅格，因其可直接表达土堆高度、可挖区域和铲斗相对作业面的空间关系。

#### 满斗率估计

满斗率估计是连接"感知"与"决策"的关键纽带。本发明提供两种可独立使用或组合使用的满斗率估计方法，分别适用于不同传感器配置场景。

**方法一：满斗率数值估计（适用于配备视觉或称重传感器的场景）**

系统根据作业面环境表示、铲斗几何形状、铲斗姿态、历史切削路径以及液压负载或称重信息，估计当前铲斗装载量：

```
fill_ratio = V_bucket_current / V_bucket_capacity
```

满斗率估计结果用于：策略模型输入、阶段切换判断、入土点/切削深度/收斗时机调整、训练奖励信号、欠装/过载/溢洒风险判断。

**方法二：基于液压憋压感知的装载状态判断（适用于仅配备压力传感器的低配置场景）**

作为方法一的补充或替代，本发明利用挖掘机液压系统的本征压力信号推断铲斗装载状态，无需外部环境感知传感器。其物理基础是：挖掘阶段铲斗入土后斗杆回收时，随着物料不断进入铲斗，斗杆液压缸大腔压力呈单调上升趋势，该趋势本质上反映了铲斗装载量的增加。系统通过监测压力信号及其与手柄控制指令的耦合关系间接判断装载状态，形成"憋压感知→手柄调整→稳定装载"的闭环控制。

**监测信号**：斗杆液压缸大腔压力P_arm_head（核心信号）、动臂液压缸大腔压力P_boom_head（辅助校验）、斗杆角度θ_arm和角速度ω_arm（判断有效挖掘行程）、斗杆手柄指令u_arm_cmd（区分主动出力与被憋停）。上述信号均为挖掘机标配或可选传感器信号，无需额外外部传感器。

**三级判断机制**：

第一级——压力幅值阈值：设定P_threshold_full，当P_arm_head持续超过该阈值且斗杆仍在手柄指令驱动下运动时，判定铲斗已接近满载。

第二级——压力变化趋势：计算dP/dt。当dP/dt正且加速上升时表明快速填充；dP/dt→0且P处于高位时表明接近憋压饱和；dP/dt负且P从高位回落时可能发生溢洒。趋势判断可弥补单一阈值对不同物料适应性差的不足——松软沙料填满时压力绝对值可能达不到硬质黏土阈值，但其趋势仍会呈现"上升后走平"的饱和特征。

第三级——手柄-压力耦合效率系数：定义η = ΔP_arm_head / Δu_arm_cmd，即单位手柄控制量产生的压力增量。η稳定表明有效装载；η持续下降表明装载效率衰减；η→0表明已满或已憋压。效率系数具有内在物料自适应性——松散物料η整体偏低但下降平缓，坚硬物料前期η高但趋近满斗时陡降明显。

**效率系数η的实时计算方法**：设定滑动时间窗口T_η，典型取1.0秒，窗口内包含至少50个采样点（采样率50Hz以上）。在每个时间步t，分别计算窗口内斗杆大腔压力的增量ΔP_t和斗杆手柄指令的累积量Δu_t：

```
ΔP_t = (1/N) · Σ_{i=0}^{N-1} P_arm_head(t - i) - (1/N) · Σ_{i=N}^{2N-1} P_arm_head(t - i)
Δu_t = Σ_{i=0}^{N-1} (u_arm_cmd(t - i) · Δt)
η_t  = ΔP_t / max(Δu_t, Δu_min)
```

其中，N为窗口内采样点数（对应T_η/采样周期），Δt为采样间隔，Δu_min为极小正数（避免零除）。为抑制单次测量噪声，对η_t序列施加一阶指数平滑：η_filt(t) = β · η_filt(t-1) + (1-β) · η_t，平滑因子β典型取0.6–0.8。

判满下限阈值η_min的设定采用相对标定法：在挖掘机空载或极浅挖掘工况下采集η的基线值η_baseline，取η_min = η_baseline × k_sat，其中k_sat为饱和系数，典型取0.15–0.25。当η_filt(t)持续低于η_min且历时超过判定延迟时间T_delay（典型0.5秒）时，确认判满。

**闭环控制逻辑**：系统以液压压力为实时反馈信号，持续监测P_arm_head、dP/dt和η，根据组合状态自动调整斗杆和铲斗的手柄指令：P低且η正常时适度加大挖掘；P高且η正常时保持；P高且η下降时减小斗杆速度并准备收斗；P超阈值或η低于下限时判断满斗并输出收斗指令；P异常跳变或η剧烈波动时触发安全约束检查。

**最小挖掘行程保护**：针对沙等低阻力物料可能出现已满而压力未达阈值的情况，设定最小挖掘行程长度L_min。当斗杆回收行程达到L_min时，即使压力信号未触发判满条件，系统也综合评估后做出收斗或浅层补挖决策。

**两方法关系**：方法一与方法二可独立部署（低配置场景仅用方法二，高配置场景仅用方法一），也可组合使用——以憋压感知作为数值估计的校验通道，结论一致时提高置信度，不一致时触发保守复核。

#### 作业阶段管理

作业阶段由FSM/BT管理。FSM负责正常循环的线性阶段调度，BT负责安全停止、人工接管和异常恢复等高优先级分支决策。阶段管理模块负责"何时切换阶段"，策略模型负责"当前阶段如何控制"——二者职责明确分离。

典型阶段序列为：复位→入土→挖掘→提升/回转→卸载→复位。阶段切换条件包括：入土到达挖掘起点、满斗率达到目标区间或憋压感知判满、铲斗到达卸载区域、以及任意阶段的越界/超深/传感器异常/执行机构饱和/人工接管等安全触发。

#### 阶段条件策略控制

策略模块采用共享状态编码器加多阶段输出头的结构：入土策略头、挖掘策略头、提升/回转策略头、卸载策略头共享底层编码器，各自独立输出阶段适宜的控制量。挖掘阶段策略输入包括作业面环境表示、满斗率估计结果、各关节角度与角速度、铲斗末端位姿、历史控制指令和当前阶段编码；输出为三轴原始控制量u_raw = [u_boom, u_arm, u_bucket]。策略根据作业面形态和满斗率估计结果调整入土点、入土角度、切削深度、斗杆回收速度、收斗时机以及是否提前终止挖掘。

#### 液压迟滞的历史序列建模

为适应液压系统的迟滞、延迟和复合动作耦合，策略模型接收历史状态和指令序列：H_t = {s_{t-n}, ..., s_t, u_{t-n}, ..., u_{t-1}}。通过LSTM、GRU、时序卷积网络或Transformer等时序编码器提取历史响应特征h_t = F_temporal(H_t)，与当前状态、作业面表示和阶段信息融合后生成控制指令。

#### 约束修正与安全保护

策略输出的原始指令须经约束修正模块处理：u_final = C(u_raw, s_t, constraints)。约束项包括：作业边界、最大挖掘深度、关节极限、液压执行机构能力、指令平滑性、负载压力风险和传感器异常。修正方式包括限幅、方向抑制、比例缩放、滤波、切换保守策略、安全停止或人工接管。

### 有益效果

与现有技术相比，本发明具有以下有益效果：

1. **解决非固定作业面满斗率不稳定**：通过满斗率估计（数值估计+憋压感知双路径）形成实时闭环反馈，使挖掘动作随土堆形态自适应调整，而非依赖固定轨迹；
2. **解决液压迟滞与控制偏差**：通过历史序列的时序编码器建模（LSTM等），使策略自动适应液压系统的迟滞、延迟和负载变化；
3. **解决多阶段目标混杂**：通过FSM/BT将阶段切换与阶段内控制解耦，各阶段采用差异化控制目标和独立策略参数；
4. **解决学习型策略的安全风险**：通过约束修正层对策略输出进行确定性安全修正，降低越界、超深和过载风险；
5. **低配置场景适用**：憋压感知方案仅需压力传感器即可工作，不受扬尘、光照影响，大幅降低部署门槛。

## 具体实施方式

以下结合实施例对本发明作进一步说明。

#### 实施例一：非固定料堆满斗率稳定控制（高配置方案）

1. 获取挖掘前方区域的深度图或点云，生成局部高度图或占据栅格；
2. 根据铲斗姿态、铲斗几何参数和作业面变化进行满斗率数值估计；
3. FSM/BT根据当前位置和作业进度确定当前作业阶段；
4. 挖掘阶段策略根据作业面表示和满斗率估计结果输出三轴控制量；
5. 约束修正模块对控制量进行安全修正；
6. 执行后更新作业面地图和满斗率估计结果；
7. 满斗率达到目标区间或液压负载风险升高时，切换至提升/卸载阶段。

#### 实施例二：带液压迟滞补偿的阶段策略控制

1. 采集历史状态与历史控制序列；
2. 通过LSTM时序编码器提取液压响应特征；
3. 将液压响应特征与作业面表示、满斗率估计结果和阶段编码融合；
4. 融合后的特征输入当前阶段策略模型，输出液压控制指令；
5. 经约束修正后驱动液压执行机构。

#### 实施例三：行为树安全管理

构建包含安全节点、异常恢复节点和自动作业节点的行为树。安全节点优先级高于自动作业节点。当检测到越界、超深、传感器异常、执行机构饱和或人工接管时，行为树立即中断当前策略执行，切换至安全停止或保守控制模式。

#### 实施例四：基于液压憋压感知的满斗率闭环控制（低配置方案）

1. 在斗杆液压缸大腔和动臂液压缸大腔安装压力传感器；通过关节编码器获取斗杆角度θ_arm和角速度ω_arm；从控制器内部获取斗杆手柄指令u_arm_cmd；
2. 铲斗入土后FSM/BT切换至挖掘阶段；
3. 以预设初始参数启动：切削深度D0、斗杆回收速度V0；
4. 以不低于50Hz持续采集P_arm_head和u_arm_cmd，在设定时间窗口内计算dP/dt和η；
5. 根据三级判断结果动态调整：P_arm_head > P_threshold_full且行程≥L_min则判满；dP/dt→0且P高位则在减小指令后继续监测确认；η < η_min且持续下降则判满；行程≥L_min且均未触发则触发最小挖掘行程保护；
6. 循环上述步骤，直至触发判满条件；
7. 输出收斗指令，收斗完成后FSM/BT切换至提升阶段；
8. 以提升阶段P_boom_head作为本循环装载量后验校验，调整下一循环参数；
9. 卸载后记录装载效果评估，更新控制参数。

本实施例仅需液压压力传感器和关节传感器（挖掘机标配），无需任何外部环境感知设备。

#### 策略模型的训练方式

上述各实施例中的阶段策略模型可通过模仿学习（行为克隆预热）、离线强化学习、仿真强化学习或其组合训练获得。

**训练数据**包括：作业面环境表示、机械状态、历史控制指令、阶段标签、人工操作指令和满斗率标签。满斗率标签可来源于称重系统、压力估计、卸载后体积测量、仿真真实值或多源融合。训练目标包括：拟合专家操作、提高满斗率区间命中率、降低多循环方差、减少欠装过载和溢洒、保持控制平滑、避免越界超深和饱和。

**强化学习奖励函数设计**（以PPO/SAC算法为例）：

挖掘阶段的奖励函数由五项加权子目标组成，各项分别对应挖掘阶段的核心控制目标：

```
R_dig = w_fill · R_fill + w_stab · R_stab + w_eff · R_eff + w_smooth · R_smooth + w_safe · R_safe
```

各子项定义如下：

**(a) 满斗率命中奖励 R_fill**：鼓励铲斗装载量落入目标区间[fill_min, fill_max]（典型值[0.80, 0.95]）。

```
R_fill = sign(fill_ratio) · [ 1 − |fill_ratio − fill_target| / (fill_max − fill_min) ],  fill_ratio ∈ [fill_min, fill_max]
R_fill = −γ_fill · (fill_target − fill_ratio)²,                                  fill_ratio < fill_min
R_fill = −γ_fill · (fill_ratio − fill_target)² − γ_spill,                         fill_ratio > fill_max
```

其中fill_target为区间中值，γ_fill为欠装/过载的二次惩罚系数（典型取2.0–5.0），γ_spill为溢洒附加惩罚（典型取5.0–10.0）。该分段函数在目标区间内提供线性奖励（鼓励趋近中值），在区间外施加二次惩罚。

**(b) 多循环稳定性奖励 R_stab**：以最近K个循环的满斗率方差σ²_fill(K)衡量，鼓励多循环满斗率波动尽量小。

```
R_stab = exp(−λ_stab · σ²_fill(K))
```

其中λ_stab为缩放系数（典型取5.0–10.0），K取最近10–20个循环。该指数映射使得方差增大时奖励快速衰减，对满斗率突降/突升施加强惩罚。

**(c) 挖掘效率奖励 R_eff**：鼓励在满足满斗率的前提下缩短单次挖掘阶段耗时T_dig。

```
R_eff = exp(−λ_eff · max(0, T_dig − T_target) / T_target)
```

其中T_target为目标挖掘时长（典型2–4秒，取决于机型和物料），λ_eff为效率惩罚系数（典型取1.0–2.0）。该设计确保系统不会为了单纯追求低方差而过度延长挖掘时间。

**(d) 控制平滑惩罚 R_smooth**：对相邻时间步之间的控制指令变化量施加惩罚，抑制抖动。

```
R_smooth = −λ_smooth · ‖u_t − u_{t-1}‖²
```

其中λ_smooth为平滑系数（典型取0.1–0.5），u_t = [u_boom, u_arm, u_bucket]为t时刻的三轴控制量。该惩罚项与液压系统的实际限制一致——过大过快的指令变化不仅造成冲击，还会加剧液压迟滞。

**(e) 安全约束奖励 R_safe**：对接约束修正模块实际被触发的程度进行惩罚。

```
R_safe = −λ_safe · δ_violation
```

其中δ_violation为约束修正模块在单步内实际执行修正的幅度（如限幅比例、缩放系数偏离1的程度等），λ_safe为安全惩罚系数（典型取1.0–3.0）。

**权重配置**：上述五项权重的典型配置为w_fill: w_stab: w_eff: w_smooth: w_safe = 5:2:1:1:3，使满斗率命中率在训练中占据主导地位，安全约束次之，效率和稳定性居中，平滑性作为辅助约束。实际应用中可根据项目需求（如优先保证安全或优先保证效率）酌情调整权重比例。

**训练环境**：仿真训练时采用包含液压系统模型（泵-阀-缸动态特性）和土壤切削模型（基于Mohr-Coulomb或Bekker力学模型）的联合仿真环境。在仿真RL训练收敛后，通过模仿学习的行为克隆损失对策略进行正则化微调，使策略在实际部署前兼具"探索优化"和"保守安全"双重特性。

## 权利要求书

### 权利要求1

一种液压挖掘机满斗率阶段条件控制系统，其特征在于，包括：

作业面感知模块，用于获取挖掘前方区域的环境信息；

作业面表示模块，用于根据所述环境信息生成作业面环境表示，所述作业面环境表示包括局部高度图、占据栅格、点云特征或局部地形地图中的至少一种；

机械状态采集模块，用于获取动臂、斗杆、铲斗的关节状态以及历史控制指令；

满斗率估计模块，用于根据作业面表示、铲斗几何参数、铲斗姿态、历史切削路径、称重信息或液压负载中的至少一种估计当前铲斗装载量或满斗率，或者通过斗杆液压缸压力信号、压力变化趋势以及压力与手柄指令耦合效率系数判断装载状态；

阶段管理模块，用于通过有限状态机、行为树或其组合，根据满斗率估计结果、目标深度、切削路径完成度、液压负载或安全状态确定并切换当前作业阶段；

阶段条件策略模块，用于根据当前作业阶段、作业面表示、机械状态、历史控制指令和满斗率估计结果生成动臂、斗杆和铲斗的原始控制指令；

约束修正模块，用于对所述原始控制指令进行安全约束修正；

液压执行控制模块，用于根据修正后的控制指令驱动液压执行机构；

其中，所述系统不以连续轨迹规划和轨迹跟踪作为必要中间步骤，轨迹信息仅作为辅助约束或参考输入。

### 权利要求2

根据权利要求1所述的系统，其特征在于，所述满斗率估计模块在挖掘阶段通过斗杆液压缸大腔压力P_arm_head、压力一阶差分dP/dt以及手柄-压力耦合效率系数η = ΔP_arm_head / Δu_arm_cmd三级判断机制判断铲斗装载状态，并根据判断结果动态调整斗杆手柄指令和铲斗手柄指令。

### 权利要求3

根据权利要求2所述的系统，其特征在于，当斗杆回收行程达到预设的最小有效挖掘行程长度L_min时，即使所述三级判断机制未触发判满条件，系统仍综合评估当前压力状态、铲斗位置和作业面预估切削深度后输出收斗指令或切换至浅层补挖模式。

### 权利要求4

根据权利要求2所述的系统，其特征在于，在提升阶段中以动臂大腔压力作为当前循环装载量的后验校验信号，若该压力低于正常满载提升压力范围则在下一次循环中增大L_min和初始切削深度，若高于正常范围则降低判满压力阈值和挖掘参数。

### 权利要求5

一种液压挖掘机满斗率阶段条件控制方法，其特征在于，包括以下步骤：

获取挖掘前方区域的环境信息并生成作业面环境表示；

根据作业面环境表示、铲斗几何参数、铲斗姿态、历史切削路径、称重信息或液压负载估计当前装载量或满斗率，或者通过液压憋压感知信号判断装载状态；

通过有限状态机、行为树或其组合确定当前作业阶段；

根据当前作业阶段调用对应的阶段策略模型或选择对应的阶段输出头，在挖掘阶段根据作业面表示、机械状态、历史控制指令和满斗率估计结果生成动臂、斗杆和铲斗控制指令；
