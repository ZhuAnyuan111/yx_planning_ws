# 一种面向非固定场景满斗率稳定的液压挖掘机阶段条件控制方法及系统

## 一、技术交底书

### 1. 发明名称

一种面向非固定场景满斗率稳定的液压挖掘机阶段条件控制方法及系统

---

### 2. 技术领域

本发明涉及工程机械自动化、液压执行系统控制和智能控制领域，具体涉及一种用于液压挖掘机自动挖掘作业的控制方法及系统。该方法面向土堆形态、作业面高度和剩余可挖土量不断变化的非固定场景，通过作业面环境表示、满斗率估计、阶段管理和阶段策略控制，提高挖掘循环中的单斗装载稳定性。

---

### 3. 背景技术

液压挖掘机自动作业通常包含复位、入土、挖掘、提升、回转、卸载等阶段。现有自动控制方案多采用如下架构：

```text
环境感知 -> 轨迹规划 -> 轨迹跟踪 -> 液压执行
```

该类方案在固定作业点和规则场景下可实现自动循环，但在非固定场景中仍存在不足：

1. 土堆形态随挖掘循环变化，固定轨迹难以持续保证铲斗装载量；
2. 液压系统存在迟滞、延迟和多执行机构耦合，轨迹跟踪误差容易放大；
3. 挖掘阶段、提升阶段和卸载阶段的控制目标不同，单一策略难以同时兼顾；
4. 若缺少作业面形态和铲斗装载状态反馈，系统难以判断入土位置、切削深度和收斗时机；
5. 学习型控制策略若直接输出执行指令，仍需要确定性安全约束进行修正。

因此，需要一种面向非固定作业面的控制方案，使系统能够根据作业面变化和满斗率反馈调整挖掘动作，同时兼顾液压系统响应特性和安全约束。

---

### 4. 发明目的

本发明旨在提供一种液压挖掘机自动挖掘控制方法及系统，重点解决：

1. 非固定作业面下单斗满斗率不稳定的问题；
2. 液压系统迟滞、延迟和复合动作耦合导致的控制偏差问题；
3. 不同作业阶段目标不同导致的策略混杂问题；
4. 学习型策略输出缺乏硬安全约束的问题。

本发明的核心流程为：

```text
作业面环境表示
        ↓
满斗率估计
        ↓
FSM/BT 阶段管理
        ↓
阶段策略模型直接输出液压控制量
        ↓
约束修正
        ↓
液压执行
```

---

### 5. 技术方案

#### 5.1 系统总体结构

系统包括：

1. 作业参数输入模块；
2. 作业面感知与环境表示模块；
3. 机械状态与历史控制采集模块；
4. 满斗率估计模块；
5. 作业阶段管理模块；
6. 阶段条件策略模块；
7. 约束修正模块；
8. 液压执行控制模块。

总体流程为：

```text
输入作业边界、目标卸载点、目标满斗率区间
        ↓
获取作业面环境表示和机械状态
        ↓
估计当前装载量或满斗率
        ↓
FSM/BT 判断当前作业阶段
        ↓
调用当前阶段策略模型
        ↓
输出动臂、斗杆、铲斗控制指令
        ↓
安全约束修正
        ↓
驱动液压执行机构
```

本方案中的控制策略不以连续轨迹规划和轨迹跟踪作为必要中间步骤，而是由阶段策略模型根据状态特征直接生成液压执行控制量。系统仍可保留作业边界、目标卸载点、阶段切换条件和安全规则。

---

#### 5.2 作业面环境表示

为在非固定场景下稳定满斗率，系统获取挖掘前方区域的环境信息，并形成作业面环境表示。该表示用于描述待挖区域形态、已挖区域变化和剩余可挖土量。

作业面环境表示可包括以下至少一种：

1. 深度图或 RGB-D 图像；
2. 点云；
3. 局部高度图；
4. 占据栅格；
5. 局部地形地图；
6. 由多帧感知数据融合得到的作业面变化图。

优选地，采用局部高度图或占据栅格作为策略输入，因为其能够直接表达土堆高度、可挖区域和铲斗相对作业面的空间关系。

---

#### 5.3 满斗率估计

系统根据作业面环境表示、铲斗几何、铲斗姿态、历史切削路径、液压负载或称重信息，估计当前装载量和满斗率：

```text
fill_ratio = V_bucket_current / V_bucket_capacity
```

其中，`V_bucket_current` 为当前铲斗装载量估计值，`V_bucket_capacity` 为铲斗标称容量或修正后的有效容量。

满斗率估计结果用于：

1. 输入挖掘阶段策略模型；
2. 判断挖掘阶段是否结束；
3. 调整入土点、切削深度和收斗时机；
4. 作为训练奖励或评价指标；
5. 判断欠装、过载或溢洒风险。

在不具备环境表示或载荷反馈时，系统可基于铲斗几何、入土深度、切削长度和循环次数估计装载量，但该方式主要适用于固定或弱变化场景，不作为非固定场景满斗率稳定控制的主要实施方式。

---

#### 5.4 作业阶段管理

作业阶段由有限状态机、行为树或二者组合给定。阶段管理模块负责“何时切换阶段”，策略模型负责“当前阶段如何控制”。

典型阶段包括：

```text
复位 -> 入土 -> 挖掘 -> 提升/回转 -> 卸载 -> 复位
```

有限状态机用于正常循环，行为树用于安全停止、人工接管和异常恢复。

典型阶段切换条件包括：

1. 复位到入土：铲斗到达挖掘起点或目标作业区域；
2. 入土到挖掘：铲斗达到预设入土深度或接触作业面；
3. 挖掘到提升：满斗率达到目标区间、切削路径完成、目标深度达到或负载风险升高；
4. 提升/回转到卸载：铲斗到达卸载区域；
5. 卸载到复位：铲斗姿态完成卸载且装载量低于阈值；
6. 任意阶段到安全停止：越界、超深、传感器异常、执行机构饱和或人工接管。

---

#### 5.5 阶段条件策略控制

阶段条件策略模块根据当前阶段调用对应阶段策略模型，或者选择共享模型的对应阶段输出头。

优选结构为：

```text
共享状态编码器
        |
        |-- 入土策略头
        |-- 挖掘策略头
        |-- 提升/回转策略头
        |-- 卸载策略头
```

其中，挖掘阶段策略是本发明的重点。其输入包括：

1. 作业面环境表示；
2. 当前满斗率估计；
3. 动臂、斗杆、铲斗角度和角速度；
4. 铲斗末端位姿；
5. 历史控制指令；
6. 当前阶段编码。

挖掘阶段策略输出：

```text
u_raw = [u_boom, u_arm, u_bucket]
```

其中，`u_boom`、`u_arm`、`u_bucket` 分别对应动臂、斗杆和铲斗控制量。根据设备配置，控制量可以是归一化手柄量、阀控电流、阀芯位移指令或底层控制器可接收的等效控制量。

挖掘阶段策略根据作业面形态和满斗率估计调整：

1. 入土点；
2. 入土角度；
3. 切削深度；
4. 斗杆回收速度；
5. 铲斗收斗时机；
6. 是否提前结束当前挖掘动作。

---

#### 5.6 液压迟滞的历史序列建模

液压执行系统存在迟滞、延迟和复合动作耦合。为适应该特性，策略模型输入历史状态和历史控制序列：

```text
H_t = {s_{t-n}, ..., s_t, u_{t-n}, ..., u_{t-1}}
```

通过 LSTM、GRU、时序卷积网络或 Transformer 等时序编码器获得历史响应特征：

```text
h_t = F_temporal(H_t)
```

策略模型根据 `h_t`、作业面环境表示、满斗率估计和当前阶段输出控制指令。历史序列用于表征控制输入与后续机械响应之间的时间关系，从而适应液压系统的延迟和负载变化。

---

#### 5.7 约束修正与安全保护

阶段策略输出的原始控制指令不直接执行，而是经过约束修正模块处理：

```text
u_final = C(u_raw, s_t, constraints)
```

约束包括：

1. 作业边界约束；
2. 最大挖掘深度约束；
3. 关节角度、速度和加速度约束；
4. 液压执行机构能力约束；
5. 控制指令平滑约束；
6. 负载或压力风险约束；
7. 传感器异常和人工接管约束。

修正方式包括限幅、方向抑制、比例缩放、滤波、切换保守策略、安全停止或人工接管。

---

### 6. 训练方式

策略模型可通过模仿学习、离线强化学习、仿真强化学习或其组合训练。

训练数据优选包括：

1. 作业面环境表示；
2. 机械状态；
3. 历史控制指令；
4. 阶段标签；
5. 人工操作指令或策略目标指令；
6. 当前装载量或满斗率标签；
7. 安全事件和异常事件标签。

满斗率标签可来自称重系统、压力/载荷估计、卸载后体积测量、仿真环境真实值或多源融合估计。

训练目标包括：

1. 使阶段策略拟合专家操作；
2. 提高满斗率落入目标区间的比例；
3. 降低多循环满斗率波动；
4. 减少欠装、过载和溢洒；
5. 保持控制平滑；
6. 避免越界、超深和执行机构饱和。

---

### 7. 具体实施方式

#### 实施例一：非固定料堆满斗率稳定控制

1. 获取挖掘前方区域的深度图或点云；
2. 生成局部高度图或占据栅格；
3. 根据铲斗姿态、铲斗几何和作业面变化估计当前满斗率；
4. FSM/BT 根据当前位置和作业进度确定当前阶段；
5. 挖掘阶段策略根据作业面表示和满斗率估计输出三轴控制量；
6. 约束修正模块对控制量进行安全修正；
7. 执行后更新作业面地图和满斗率估计；
8. 当满斗率达到目标区间或负载风险升高时，切换至提升/卸载阶段。

#### 实施例二：带液压迟滞补偿的阶段策略控制

1. 采集历史状态和历史控制指令；
2. 通过时序编码器提取液压响应特征；
3. 将液压响应特征与作业面表示、满斗率估计和阶段编码融合；
4. 输出当前阶段的液压控制指令；
5. 经约束修正后驱动液压执行机构。

#### 实施例三：行为树安全管理

行为树设置安全节点、异常恢复节点和自动作业节点。安全节点优先级高于自动作业节点。当检测到越界、超深、传感器异常、执行机构饱和或人工接管时，行为树中断当前阶段策略，切换至安全停止、保守控制或人工接管。

---

### 8. 有益效果

本发明具有以下效果：

1. 通过作业面环境表示和满斗率估计，使挖掘动作能够随土堆形态变化调整；
2. 通过 FSM/BT 阶段管理，将阶段切换逻辑与阶段内控制策略解耦；
3. 通过阶段策略模型，使入土、挖掘、提升、卸载等阶段采用不同控制目标；
4. 通过历史序列建模，适应液压系统迟滞、延迟和负载变化；
5. 通过约束修正模块，降低学习型策略直接控制液压执行机构的安全风险；
6. 通过满斗率目标和多循环稳定性评价，提高非固定场景下单斗装载稳定性。

上述效果与传感器配置、训练数据、机型和作业环境有关，不限定为固定精度或固定性能指标。

## 二、权利要求书初稿方向

### 权利要求1：系统权利要求

一种面向非固定场景满斗率稳定的液压挖掘机阶段条件控制系统，其特征在于，包括：

1. 作业面感知模块，用于获取挖掘前方区域的环境信息；
2. 作业面表示模块，用于根据所述环境信息生成局部高度图、占据栅格、点云特征或局部地形地图；
3. 机械状态采集模块，用于获取动臂、斗杆、铲斗的状态以及历史控制指令；
4. 满斗率估计模块，用于根据作业面表示、铲斗几何、铲斗姿态、历史切削路径、称重信息或液压负载中的至少一种估计当前装载量或满斗率；
5. 阶段管理模块，用于根据有限状态机、行为树或其组合确定当前作业阶段；
6. 阶段条件策略模块，用于根据当前作业阶段、作业面表示、机械状态、历史控制指令和满斗率估计结果生成液压执行机构的原始控制指令；
7. 约束修正模块，用于对所述原始控制指令进行安全约束修正；
8. 液压执行控制模块，用于根据修正后的控制指令驱动液压执行机构。

其中，所述阶段管理模块根据满斗率、目标深度、切削路径完成度、液压负载或安全状态触发阶段切换；所述阶段条件策略模块在挖掘阶段根据作业面表示和满斗率估计结果调整入土点、切削深度、斗杆回收速度或铲斗收斗时机。

### 权利要求2：方法权利要求

一种面向非固定场景满斗率稳定的液压挖掘机阶段条件控制方法，其特征在于，包括：

1. 获取挖掘前方区域的环境信息，并生成作业面环境表示；
2. 获取液压挖掘机机械状态和历史控制指令；
3. 根据作业面环境表示、铲斗几何、铲斗姿态、历史切削路径、称重信息或液压负载估计当前装载量或满斗率；
4. 通过有限状态机、行为树或其组合确定当前作业阶段；
5. 根据当前作业阶段调用对应阶段策略模型或选择对应阶段输出头；
6. 在挖掘阶段，根据作业面环境表示、机械状态、历史控制指令和满斗率估计结果生成动臂、斗杆和铲斗控制指令；
7. 对所述控制指令进行约束修正；
8. 根据修正后的控制指令驱动液压执行机构；
9. 执行后更新作业面环境表示和满斗率估计结果。

### 权利要求3：从属权利要求方向

可进一步限定：

1. 作业面环境表示包括深度图、点云、局部高度图、占据栅格或局部地形地图；
2. 阶段管理模块包括有限状态机和行为树，行为树用于安全停止、异常恢复和人工接管；
3. 阶段策略模型包括共享状态编码器和多个阶段输出头；
4. 策略模型包括用于处理历史状态和历史控制序列的 LSTM、GRU、时序卷积网络或 Transformer；
5. 满斗率估计结果用于触发由挖掘阶段向提升或卸载阶段的切换；
6. 挖掘阶段策略根据满斗率估计结果调整入土角度、切削深度或收斗时机；
7. 约束修正包括作业边界约束、最大深度约束、关节极限约束、液压负载约束和控制平滑约束；
8. 策略模型通过模仿学习、离线强化学习、仿真强化学习或其组合训练获得。

## 三、实施与验证建议

建议优先验证最小闭环：

1. 使用深度相机或激光雷达生成局部高度图；
2. 采集人工挖掘数据，包含阶段标签、控制指令和满斗率标签；
3. 训练挖掘阶段策略，使其学习入土点、切削深度和收斗时机；
4. 使用 FSM/BT 管理阶段切换；
5. 使用约束修正模块限制越界、超深、过载和控制突变；
6. 以单斗满斗率目标区间命中率、多循环满斗率方差、安全接管次数作为主要评价指标。

本专利方案应聚焦于“非固定场景下基于作业面表示和满斗率估计的阶段条件液压控制”，不建议再扩展为通用无人挖掘机全场景控制方案。
