## 📋 12篇竞争专利详细分析

### 一、最接近的3篇关键竞争专利

#### 1️⃣ **CN114351785B** ⚠️ 威胁最高

**基本信息**

```
专利号：      CN114351785B
名称：        一种液压挖掘机的流量分配方法和系统
申请人：      小松制作所（Komatsu Ltd.）
申请日期：    2021-05-31
公开日期：    2023-10-17
IPC分类：     E02F 9/28
相似度评分：  ⭐⭐⭐⭐⭐ 8.5/10
```

**技术方案概述**

- 使用深度强化学习（DRL）优化液压挖掘机的流量分配
- 目标：提高能效、降低油耗
- 方法：Q-learning或DQN网络优化流量阀门开度
- 输入：液压压力、流量、发动机转速等传感信号
- 输出：流量分配指令

**与我方方案的相同点**

```
✗ 都使用强化学习（RL）
✗ 都针对液压挖掘机
✗ 都考虑系统延迟补偿
✗ 都涉及多轴协调
```

**与我方方案的核心差异** ✅

| 维度 | CN114351785B | 我方方案 |
|------|------------|---------|
| **优化目标** | 单一：能效/油耗 | 多维：土方量(40%) + 质量(30%) + 平滑(15%) + 效率(10%) + 安全(5%) |
| **控制层级** | 流量分配层（中层） | 端到端：状态→控制信号（最外层） |
| **轨迹规划** | 保留轨迹规划 → 轨迹跟踪 → 流量优化（3层） | 去除轨迹规划：状态 → 策略 → 控制（2层） |
| **阶段建模** | 无 | **有三阶段条件**：π(s, phase) |
| **控制信号** | 流量阀指令（间接） | 直接手柄信号(3轴) |
| **传感器依赖** | 高（压力/流量/温度） | 低（无压力传感器，间接估计） |
| **视觉输入** | 无 | **有CNN图像编码** |
| **土方量评估** | 无（仅能耗） | **有完整的土方量与质量评估** |
| **硬约束层** | 无 | **有几何+液压+安全硬约束** |

**权利范围的差异化规避**

```
CN114351785B的权利范围：
  →  "液压流量分配的强化学习优化方法"
  
我方应避免的重合写法：
  ✗ 不能仅强调"强化学习优化"
  ✗ 不能说"液压系统控制"（过于宽泛）

我方应强调的独特点：
  ✓ "基于作业阶段(phase)条件的端到端策略生成"
  ✓ "去除轨迹规划中间层，直接从状态生成控制信号"
  ✓ "融合视觉特征与机械状态的多模态端到端控制"
  ✓ "硬约束安全层确保所有输出的可控性"
  ✓ "支持土方量与作业质量的多维度评估"
```

**规避策略**

- 在权利要求书中，第一项独立权利要求应强调"三阶段条件策略"而非单一全局策略
- 强调"去轨迹规划"的本质区别（它的流量优化仍在轨迹跟踪框架内）
- 强调"多目标平衡"与它的"单一能效目标"的差异
- 在说明书中详细说明为何多目标优化在商用价值上优于单目标能效优化

**侵权风险评估**

```
风险等级：    🟡 中等
基本理由：    
  - 它是流量优化层，我是完整控制层
  - 它保留轨迹规划，我去除轨迹规划
  - 应该不构成直接侵权，但需在权利要求中明确区分

建议：        避免权利要求过宽，明确限定为"去轨迹规划"+"阶段条件"
```

## 2. 本专利的技术方案

本专利提出一种面向非固定作业面的液压挖掘机满斗率稳定控制方法及系统。

核心流程如下：

```text
作业面环境表示
        ↓
满斗率估计
        ↓
FSM/BT 阶段管理
        ↓
阶段策略模型输出液压控制量
        ↓
约束修正
        ↓
液压执行
```

系统包括以下模块：

1. **作业面感知模块**  
   获取挖掘前方区域的深度图、点云、局部高度图、占据栅格或局部地形地图。

2. **作业面表示模块**  
   将原始感知数据转换为可供策略使用的作业面环境表示，描述待挖区域形态、已挖区域变化和剩余可挖土量。

3. **机械状态与历史控制采集模块**  
   获取动臂、斗杆、铲斗的角度、角速度、铲斗末端位姿以及历史控制指令。

4. **满斗率估计模块**  
   根据作业面表示、铲斗几何、铲斗姿态、历史切削路径、称重信息或液压负载估计当前装载量和满斗率：

   ```text
   fill_ratio = V_bucket_current / V_bucket_capacity
   ```

5. **作业阶段管理模块**  
   采用有限状态机、行为树或二者组合管理作业阶段，例如：

   ```text
   复位 -> 入土 -> 挖掘 -> 提升/回转 -> 卸载 -> 复位
   ```

6. **阶段条件策略模块**  
   根据当前阶段调用对应阶段策略模型，或选择共享模型的对应阶段输出头。在挖掘阶段，策略模型根据作业面表示、机械状态、历史控制和满斗率估计结果生成控制指令。

7. **约束修正模块**  
   对策略输出进行作业边界、最大深度、关节极限、液压负载和平滑性约束修正。

8. **液压执行控制模块**  
   将修正后的控制指令转换为动臂、斗杆、铲斗等液压执行机构的控制量。

## 3. 背景技术介绍

### 3.1 现有方案通常怎么做

现有无人挖掘机或自动挖掘控制系统通常采用以下路线：

```text
环境感知 -> 轨迹规划 -> 轨迹跟踪 -> 液压执行
```

常见做法包括：

1. **基于轨迹规划的自动挖掘**  
   根据目标挖掘区域生成铲斗路径，再由控制器跟踪该路径。

2. **基于阶段识别的作业分析**  
   通过压力、角度、油耗或传感数据识别挖掘机当前处于挖掘、回转、卸载等阶段。

3. **基于效率检测的作业评价**  
   根据循环时间、油耗、工作状态等评价挖掘机作业效率。

4. **基于学习模型的路径或参数优化**  
   使用机器学习优化路径、轨迹、流量分配或控制参数。

### 3.2 现有方案的缺点

1. **轨迹规划难以适应非固定作业面**  
   土堆形态随每次挖掘不断变化，预先规划或优化出的轨迹很难持续适应作业面变化。

2. **缺少满斗率闭环**  
   许多方案关注轨迹、效率或阶段识别，但没有将当前满斗率作为策略输入和阶段切换条件，因此难以稳定控制单斗装载量。

3. **阶段识别与控制决策脱节**  
   现有阶段识别专利通常解决“当前是什么阶段”，但没有进一步解决“当前阶段如何调整入土点、切削深度和收斗时机”。

4. **液压系统迟滞导致跟踪误差**  
   液压挖掘机存在迟滞、延迟和复合动作耦合，传统轨迹跟踪容易出现控制滞后、动作振荡或装载不足。

5. **学习型控制缺少安全兜底**  
   如果学习模型直接输出液压控制指令，可能出现越界、超深、过载、动作突变等风险。

## 4. 发明内容

本发明计划通过以下方式解决上述问题：

1. **用作业面环境表示描述非固定场景**  
   通过深度图、点云、局部高度图、占据栅格或局部地形地图表示待挖区域，使系统知道哪里有土、哪里已挖空、哪里适合作为入土点。

2. **用满斗率估计建立装载反馈**  
   通过作业面变化、铲斗姿态、历史切削路径、称重信息或液压负载估计当前满斗率，使系统能够判断当前是否欠装、接近满斗或存在过载风险。

3. **用 FSM/BT 管理作业阶段**  
   正常作业由 FSM 管理阶段顺序，异常处理和人工接管由行为树管理。阶段切换不仅依赖位置，也依赖满斗率、目标深度、切削路径完成度和负载风险。

4. **用阶段策略模型生成控制指令**  
   在挖掘阶段，策略模型根据作业面表示、满斗率估计、机械状态和历史控制，输出动臂、斗杆、铲斗控制量，并动态调整入土点、切削深度、斗杆回收速度和收斗时机。

5. **用历史序列处理液压迟滞**  
   将历史状态和历史控制指令输入时序模型，表征控制输入与机械响应之间的延迟关系，提高液压控制稳定性。

6. **用约束修正保证安全执行**  
   对策略输出进行作业边界、最大深度、关节极限、液压负载和控制平滑修正，必要时切换至保守策略、人工接管或安全停止。

## 5. 本发明的优点

1. **满斗率控制目标明确**  
   本发明不是泛泛地自动挖掘，而是明确面向非固定作业面下的单斗满斗率稳定问题。

2. **适应非固定作业面**  
   通过局部高度图、点云或占据栅格表示作业面变化，使系统能够根据剩余可挖土量动态调整挖掘动作。

3. **阶段管理更工程化**  
   FSM/BT 将阶段切换、安全停止、异常恢复和人工接管分离管理，比完全黑盒控制更易部署和验证。

4. **挖掘动作可闭环调节**  
   满斗率估计结果直接参与策略输入和阶段切换，能够动态调整入土点、切削深度和收斗时机。

5. **降低液压迟滞影响**  
   历史状态和历史控制序列可用于学习液压系统延迟和负载变化，提高控制平稳性。

6. **安全性更强**  
   学习策略输出不直接执行，而是经过约束修正，降低越界、超深、过载和动作突变风险。

## 6. 本发明的关键点和保护点

### 6.1 关键技术点

1. **基于作业面环境表示的非固定场景建模**  
   将深度图、点云、局部高度图、占据栅格或局部地形地图作为控制策略输入。

2. **满斗率估计闭环**  
   根据作业面表示、铲斗几何、铲斗姿态、历史切削路径、称重信息或液压负载估计当前满斗率。

3. **满斗率驱动的阶段切换**  
   FSM/BT 根据满斗率、目标深度、切削路径完成度、液压负载或安全状态触发阶段切换。

4. **挖掘阶段策略调节动作参数**  
   挖掘阶段策略根据作业面表示和满斗率估计结果调整入土点、切削深度、斗杆回收速度或铲斗收斗时机。

5. **历史序列建模液压迟滞**  
   使用历史状态和历史控制指令表征液压系统迟滞、延迟和复合动作耦合。

6. **约束修正安全层**  
   对策略输出进行作业边界、最大深度、关节极限、液压负载和控制平滑修正。

### 6.2 建议重点保护的权利要求方向

1. 一种系统，其包括作业面表示模块、满斗率估计模块、阶段管理模块、阶段策略模块和约束修正模块。
2. 一种方法，其根据作业面表示估计满斗率，并将满斗率用于挖掘阶段策略输入和阶段切换。
3. 挖掘阶段策略根据满斗率估计结果调整入土点、切削深度、斗杆回收速度和收斗时机。
4. 阶段管理模块采用 FSM/BT，根据满斗率、目标深度、切削路径完成度、液压负载和安全状态触发切换。
5. 策略模型输入历史状态和历史控制序列，以适应液压迟滞。
6. 约束修正模块对原始控制指令进行安全修正后再执行。

## 7. 替代方式

### 7.1 作业面表示的替代方式

可采用以下任一种或多种：

1. RGB-D 图像；
2. 深度图；
3. 激光雷达点云；
4. 局部高度图；
5. 占据栅格；
6. 数字高程图；
7. 外部测量设备或施工地图生成的局部地形图。

### 7.2 满斗率估计的替代方式

可采用以下任一种或多种：

1. 基于作业面变化的体积差分估计；
2. 基于铲斗几何、入土深度和切削长度的几何估计；
3. 基于动臂压力、液压负载或泵负载的载荷估计；
4. 基于称重传感器的直接估计；
5. 基于视觉、深度图或点云的学习模型估计；
6. 多源融合估计。

### 7.3 阶段管理的替代方式

可采用：

1. 有限状态机；
2. 行为树；
3. 规则引擎；
4. 状态机与行为树组合；
5. 学习型阶段识别模型与规则切换组合。

### 7.4 阶段策略模型的替代方式

可采用：

1. 多个独立阶段策略模型；
2. 共享编码器 + 多阶段输出头；
3. 统一策略模型 + 阶段编码；
4. 模仿学习策略；
5. 离线强化学习策略；
6. 仿真强化学习策略；
7. 传统控制器与学习策略混合。

### 7.5 液压迟滞建模的替代方式

可采用：

1. LSTM；
2. GRU；
3. 时序卷积网络；
4. Transformer；
5. 滑动窗口历史特征；
6. 显式延迟补偿模型；
7. 数据驱动模型与物理模型结合。

### 7.6 安全约束的替代方式

可采用：

1. 控制限幅；
2. 方向抑制；
3. 比例缩放；
4. 平滑滤波；
5. 控制屏障函数；
6. 传统控制器兜底；
7. 人工接管；
8. 安全停止。
