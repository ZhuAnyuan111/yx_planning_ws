# 一种基于作业状态闭环的液压挖掘机阶段条件直接控制方法及系统

## 一、技术交底书

### 1. 发明名称

一种基于作业状态闭环的液压挖掘机阶段条件直接控制方法及系统

---

### 2. 技术领域

本发明涉及工程机械自动化、液压执行系统控制和智能控制领域，具体涉及一种用于液压挖掘机自动挖掘作业的控制方法及系统。该方法面向土堆形态、作业面高度和剩余可挖土量不断变化的非固定场景，通过作业面环境表示、作业状态估计（含满斗率和液压负载）、阶段管理和阶段策略控制，在提高挖掘循环中单斗装载稳定性的同时，防止长时间憋压并提升挖掘效率。

---

### 3. 背景技术

液压挖掘机自动作业通常包含复位、入土、挖掘、提升、回转、卸载等阶段。现有自动控制方案多采用如下架构：

```text
环境感知 -> 轨迹规划 -> 轨迹跟踪 -> 液压执行
```

该类方案在固定作业点和规则场景下可以工作，但在非固定场景中存在以下问题：

1. **土堆形态随循环变化，固定轨迹不再适用**：非固定作业面的土堆高度、坡面形态和剩余可挖量随每次挖掘循环持续变化，固定轨迹无法跟随作业面变化调整入土点和切削深度，导致单斗装载量不稳定。

2. **液压系统延迟与迟滞使轨迹跟踪产生不可忽视的系统性误差**：液压挖掘机执行系统存在以下固有特性，使轨迹跟踪在挖掘阶段难以奏效：
   - **阀控延迟**：从控制指令发出到液压阀芯响应，典型延迟为 80 ms ～ 200 ms；
   - **液压油路迟滞**：油液可压缩性和管路容积导致压力建立滞后，动臂、斗杆和铲斗各执行机构响应时间存在差异，典型范围为 100 ms ～ 400 ms；
   - **多执行机构耦合**：动臂、斗杆和铲斗同时动作时，各油缸负载相互影响，实际运动轨迹偏离规划轨迹；
   - **负载非线性**：切削阻力随土质、入土深度和切削角度剧烈变化，液压系统实际输出力矩难以被轨迹跟踪控制器准确预测。

   上述因素叠加后，挖掘阶段轨迹跟踪误差可达规划轨迹偏差的 20%～40%，切削阻力突变时更可能触发执行机构饱和。传统轨迹跟踪方案（如 PID、前馈补偿）需针对液压非线性精密标定，工程成本高且泛化性差。

   更关键的是，即便采用**实时感知+动态轨迹重规划**的改进方案，也无法从根本上解决该问题。当系统实时检测到需要调整动作（例如判断出应当提升动臂或加快收斗）、并据此重新规划出一条更合适的轨迹时，**仍需经历完整的控制响应链路**：

   ```text
   感知系统判断需要调整动作
           ↓
   重新规划更新后的轨迹
           ↓
   控制器计算新轨迹的跟踪误差
           ↓
   下发控制指令至液压阀
           ↓
   液压执行机构响应（延迟 80 ms ～ 400 ms）
           ↓
   执行机构实际产生动作
   ```

   在挖掘阶段，土堆形态和切削阻力的变化速率远快于上述响应链路的完成速度。实际工程中可观察到：系统判断出需要提升动臂时，到动臂真正抬升的时刻，铲斗已完成了额外的切削行程，作业面状态已显著改变，轨迹重规划的结果已部分失效；挖掘过程中如需紧急减小切削深度，控制指令下达后的液压响应滞后足以使铲斗继续下切 10 cm ～ 20 cm，造成过载或卡斗。**响应链路中每增加一个中间层（轨迹规划层、跟踪误差计算层），时序错位就累积一次**，最终导致即使具备高质量的实时感知能力，控制效果也难以达到预期。

   此外，即便实时重规划能够提供更合适的参考轨迹，**跟踪该更新轨迹本身对控制算法提出了极高的工程要求**：铲斗与土壤持续交互，土壤切削阻力高度非线性且不可预测，阻力峰值可在极短时间内发生数倍变化——这意味着克服阻力所需的控制信号大小在不同工况下差异显著，难以通过固定增益标定适配。若更新轨迹要求加快收斗或提升动臂，控制器需输出较大控制信号克服当前阻力，而在液压延迟和多执行机构耦合条件下，信号从输出到产生预期动作之间存在不可忽略的滞后，难以迅速达到轨迹要求的运动状态；若为追求响应速度而进一步增大信号，又极易引发过冲、振荡或执行机构饱和。轨迹跟踪控制器需针对不同土质、含水量和挖掘姿态进行精密增益标定和抗饱和设计，工程难度极大且泛化性差。相比之下，直接控制方案的策略模型通过历史控制序列感知当前液压系统的响应状态，可在输出控制量时隐式兼顾当前阻力条件，无需将"跟踪误差"放大为大控制信号，从而降低饱和和振荡风险。

3. **轨迹跟踪中间层与装载目标不对齐**：挖掘阶段真正的控制目标是"满斗率达标"，而非"精确沿轨迹运动"。现有方案以轨迹跟踪误差为反馈，控制器持续修正位置偏差，但液压延迟使修正动作滞后，进而引起振荡或过度修正，控制响应既不直观也不迅速。此外，即便轨迹跟踪精确，也不能保证装载量达标——装载量由作业面形态与铲斗运动的综合效果决定，轨迹精度与装载目标之间缺乏直接映射关系。

4. 挖掘、提升和卸载阶段的控制目标不同，单一策略难以同时兼顾；

5. 若缺少作业面形态和铲斗装载状态反馈，系统难以判断入土位置、切削深度和收斗时机；

6. 学习型策略若直接输出执行指令，仍需要确定性安全约束进行修正。

上述问题的根本矛盾在于：**现有方案将"沿轨迹运动"作为挖掘控制的中间目标，而液压系统的延迟和非线性特性导致该中间目标本身难以精确实现；同时，轨迹精度与装载目标之间缺乏直接映射**。此外，现有方案缺少对液压负载状态的闭环利用——实际挖掘中，铲斗遇硬质土体或切削深度过大时，液压系统长时间处于高压憋压状态，既损伤液压元件又大幅降低作业效率，而轨迹跟踪方案缺乏将负载状态直接纳入阶段切换和策略决策的机制。因此，需要一种**以作业状态（满斗率+液压负载）直接引导、跳过轨迹跟踪中间层**的控制方案，使控制器能够根据实时满斗率估计、液压负载状态和作业面表示直接输出液压执行控制量，响应更加直接迅速，同时通过负载状态闭环及时退出挖掘阶段，防止长时间憋压，提升挖掘效率。

本发明以满斗率目标和液压负载安全共同引导控制生成，将作业面表示、满斗率估计、液压负载状态和阶段条件直接作为策略模型输入，**跳过轨迹规划和轨迹跟踪中间层，直接输出液压执行控制量**，消除轨迹跟踪误差链对装载结果的干扰，提高控制响应速度和目标对齐度。

---

### 4. 发明目的

本发明旨在提供一种液压挖掘机自动挖掘控制方法及系统，重点解决：

1. **非固定作业面下单斗满斗率不稳定的问题**：作业面形态随循环变化，固定轨迹无法持续保证装载量；

2. **液压系统延迟与迟滞导致轨迹跟踪效果差的问题**：液压阀控延迟（80 ms ～ 200 ms）、油路迟滞（100 ms ～ 400 ms）和多执行机构耦合，使得以轨迹跟踪为核心的控制链路存在系统性跟踪误差，且液压延迟使跟踪修正动作进一步滞后，控制响应迟缓；

3. **轨迹跟踪中间层与装载目标不对齐的问题**：即便轨迹跟踪精确，也不能保证满斗率达标；以满斗率目标直接引导控制，绕过轨迹中间层，能够更直观、更迅速地响应装载状态变化；

4. **实时重规划轨迹仍无法解决响应链路时序错位、且土壤交互使轨迹跟踪对控制算法要求极高的问题**：即便采用实时感知+动态重规划，从"判断需要调整动作"到"执行机构真正响应"仍需经历轨迹重规划、跟踪误差计算、液压响应等多个串联延迟；与此同时，铲斗与土壤交互产生的切削阻力高度非线性，跟踪更新轨迹需输出较大控制信号，在液压延迟条件下极易引发过冲或执行机构饱和，对控制算法标定和鲁棒性要求极高、工程泛化性差；

5. **不同作业阶段目标不同导致的策略混杂问题**：挖掘、提升和卸载阶段的控制目标不同，需要分阶段策略；

6. **学习型策略输出缺乏硬安全约束的问题**：直接控制液压执行机构的学习策略需经过确定性约束修正。

7. **现有方案缺乏液压负载状态闭环、长时间憋压降低作业效率的问题**：轨迹跟踪方案中，液压负载通常仅作为安全限值使用，未被纳入阶段切换和策略决策的闭环；挖掘过程遇硬质土体时无法及时退出，长时间憋压损伤液压元件且大幅降低作业效率；本发明将液压负载与满斗率共同作为作业状态反馈，通过负载触发的阶段切换和策略调整，防止长时间憋压，提升挖掘效率。

本发明的核心流程为：

```text
作业面环境表示
        ↓
满斗率估计 ──── 液压负载监测
        ↓              ↓
      作业状态（装载+负载）
        ↓
FSM/BT 阶段管理
        ↓
阶段策略模型直接输出液压控制量
        ↓
约束修正
        ↓
液压执行
```

### 5. 技术方案

系统包括：

1. 作业参数输入模块；
2. 作业面感知与环境表示模块；
3. 机械状态与历史控制采集模块；
4. 满斗率估计模块；
5. 作业阶段管理模块；
6. 阶段条件策略模块；
7. 约束修正模块；
8. 液压执行控制模块。

```text
│  └──────────────┴────────────────────┴──────────────────┘        │
└──────────────────────────┬───────────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────────┐
│                    【执行层】                                     │
│                                                                  │
│  液压执行机构（动臂油缸 · 斗杆油缸 · 铲斗油缸）                   │
│                                                                  │
│  执行后:                                                          │
│    → 更新作业面高度图（H_t 差分更新）                             │
│    → 更新满斗率估计值 fill_ratio(t+1)                             │
│    → 更新液压负载状态 load_state(t+1)                             │
│    → 记录历史控制序列 u_{t+1}                                     │
│    → 反馈至感知层（下一控制周期）                                  │
└──────────────────────────────────────────────────────────────────┘

【与传统方案的本质区别】
传统: 感知 → 轨迹规划 → 轨迹跟踪 → PID/MPC → 控制量 → 液压执行
                    ↑           ↑
              两处轨迹中间层（本发明已移除）

本发明: 感知 → 作业状态估计 → 阶段策略直接输出 → 约束修正 → 液压执行
                 ↑                            ↑
          双信号闭环反馈              跳过两层中间转换
```

**本方案的核心区别特征**：阶段策略模型根据作业面环境表示、满斗率估计结果、液压负载状态、机械状态和历史控制序列，**直接生成动臂、斗杆和铲斗的液压执行控制量，不以连续轨迹规划和轨迹跟踪作为必要中间步骤**。轨迹信息仅可作为辅助约束或参考输入，而非控制链路的必要中间层。这与现有方案"感知→轨迹规划→跟踪误差→PID/MPC→控制量"的两层结构存在本质区别，消除了轨迹规划误差与跟踪误差的串联放大，更适应液压系统非线性和作业面动态变化。同时，满斗率和液压负载共同构成**作业状态闭环**：满斗率确保单斗装载达标，液压负载确保挖掘过程不长时间憋压，两者协同提升作业效率。

---

#### 5.2 作业面环境表示
 
为在非固定场景下稳定满斗率，系统获取挖掘前方区域的环境信息，并形成作业面环境表示。该表示用于描述待挖区域形态、已挖区域变化和剩余可挖土量。

作业面环境表示可包括以下至少一种：

1. 深度图或 RGB-D 图像；
2. 点云；
3. 局部高度图；
4. 占据栅格；
5. 局部地形地图。

优选地，采用局部高度图或占据栅格作为策略输入，因为其能够直接表达土堆高度、可挖区域和铲斗相对作业面的空间关系。

---

#### 5.3 满斗率估计

系统根据作业面环境表示、铲斗几何、铲斗姿态、历史切削路径、液压负载或称重信息，估计当前装载量和满斗率：

```text
fill_ratio = V_bucket_current / V_bucket_capacity
```

其中，`V_bucket_current` 为当前铲斗装载量估计值，`V_bucket_capacity` 为铲斗标称容量或修正后的有效容量。

满斗率估计结果用于：

1. 输入挖掘阶段策略模型；
2. 判断挖掘阶段是否结束；
3. 调整入土点、切削深度和收斗时机；
4. 作为训练奖励或评价指标；
5. 判断欠装、过载或溢洒风险。

在不具备环境表示或载荷反馈时，系统可基于铲斗几何、入土深度、切削长度和循环次数估计装载量，但该方式主要适用于固定或弱变化场景，不作为非固定场景满斗率稳定控制的主要实施方式。

---

#### 5.4 作业阶段管理

作业阶段由有限状态机、行为树或二者组合给定。阶段管理模块负责“何时切换阶段”，策略模型负责“当前阶段如何控制”。

典型阶段包括：

```text
复位 -> 入土 -> 挖掘 -> 提升/回转 -> 卸载 -> 复位
```

有限状态机用于正常循环，行为树用于安全停止、人工接管和异常恢复。

典型阶段切换条件包括：

1. 复位到入土：铲斗到达挖掘起点或目标作业区域；
2. 入土到挖掘：铲斗达到预设入土深度或接触作业面；
3. 挖掘到提升：满斗率达到目标区间、切削路径完成、目标深度达到或负载风险升高；
4. 提升/回转到卸载：铲斗到达卸载区域；
5. 卸载到复位：铲斗姿态完成卸载且装载量低于阈值；
6. 任意阶段到安全停止：越界、超深、传感器异常、执行机构饱和或人工接管。

其中，由液压负载风险升高触发的阶段切换（条件3中的"负载风险升高"）为本发明区别于单纯满斗率闭环的重要特征：当铲斗遇到硬质土体、切削阻力骤增致使液压系统压力持续偏高时，阶段管理模块无需等待满斗率达标即可提前触发挖掘到提升的切换，避免液压系统长时间处于憋压状态。此举兼具保护液压元件的安全功能和缩短无效切削时间、提升循环效率的功能。

---

#### 5.5 阶段条件策略控制

阶段条件策略模块根据当前阶段调用对应阶段策略模型，或者选择共享模型的对应阶段输出头。

优选结构为：

```text
共享状态编码器
        |
        |-- 入土策略头
        |-- 挖掘策略头
        |-- 提升/回转策略头
        |-- 卸载策略头
```

其中，挖掘阶段策略是本发明的重点。其输入包括：

1. 作业面环境表示；
2. 当前满斗率估计；
3. 动臂、斗杆、铲斗角度和角速度；
4. 铲斗末端位姿；
5. 历史控制指令；
6. 当前阶段编码。

挖掘阶段策略的完整数据流如下：

```text
输入特征：
  - 作业面环境表示（局部高度图/占据栅格，形状 H×W×C）
  - 满斗率估计值 fill_ratio ∈ [0,1]
  - 机械状态向量 [θ_boom, θ_arm, θ_bucket, ω_boom, ω_arm, ω_bucket, p_ee]
  - 历史控制序列 [u_{t-n}, ..., u_{t-1}]
  - 当前阶段编码（one-hot 或嵌入向量）
        ↓
共享状态编码器（CNN + 时序编码器）
        ↓
融合特征向量 z_t
        ↓
当前阶段输出头（挖掘头）
        ↓
【直接输出液压执行控制量】
u_raw = [u_boom, u_arm, u_bucket]
（不经过轨迹规划，不依赖轨迹跟踪误差）
```

其中，`u_boom`、`u_arm`、`u_bucket` 分别对应动臂、斗杆和铲斗**液压执行控制量**。根据设备配置，控制量可以是归一化手柄量、阀控电流、阀芯位移指令或底层控制器可接收的等效控制量。**该控制量由策略模型直接输出，无需经过中间轨迹规划层或轨迹跟踪控制器转换。**

挖掘阶段策略根据作业面形态和满斗率估计调整：

1. 入土点；
2. 入土角度；
3. 切削深度；
4. 斗杆回收速度；
5. 铲斗收斗时机；
6. 是否提前结束当前挖掘动作。

---

#### 5.6 液压迟滞的历史序列建模

液压执行系统存在迟滞、延迟和复合动作耦合。为适应该特性，策略模型输入历史状态和历史控制序列：

```text
H_t = {s_{t-n}, ..., s_t, u_{t-n}, ..., u_{t-1}}
```

通过 LSTM、GRU、时序卷积网络或 Transformer 等时序编码器获得历史响应特征：

```text
h_t = F_temporal(H_t)
```

策略模型根据 `h_t`、作业面环境表示、满斗率估计和当前阶段输出控制指令。

---

#### 5.7 约束修正与安全保护

阶段策略输出的原始控制指令不直接执行，而是经过约束修正模块处理：

```text
u_final = C(u_raw, s_t, constraints)
```

约束包括：

1. 作业边界约束；
2. 最大挖掘深度约束；
3. 关节角度、速度和加速度约束；
4. 液压执行机构能力约束；
5. 控制指令平滑约束；
6. 负载或压力风险约束；
7. 传感器异常和人工接管约束。

修正方式包括限幅、方向抑制、比例缩放、滤波、切换保守策略、安全停止或人工接管。

---

### 6. 训练方式

策略模型可通过模仿学习、离线强化学习、仿真强化学习或其组合训练。

训练数据优选包括：

1. 作业面环境表示；
2. 机械状态；
3. 历史控制指令；
4. 阶段标签；
5. 人工操作指令或策略目标指令；
6. 当前装载量或满斗率标签；
7. 安全事件和异常事件标签。

满斗率标签可来自称重系统、压力/载荷估计、卸载后体积测量、仿真环境真实值或多源融合估计。

训练目标包括：

1. 使阶段策略拟合专家操作；
2. 提高满斗率落入目标区间的比例；
3. 降低多循环满斗率波动；
4. 减少欠装、过载和溢洒；
5. 保持控制平滑；
6. 避免越界、超深和执行机构饱和。

### 7. 具体实施方式

#### 实施例一：非固定料堆满斗率稳定控制

1. 获取挖掘前方区域的深度图或点云；
2. 生成局部高度图或占据栅格；
3. 根据铲斗姿态、铲斗几何和作业面变化估计当前满斗率；
4. FSM/BT 根据当前位置和作业进度确定当前阶段；
5. 挖掘阶段策略根据作业面表示和满斗率估计输出三轴控制量；
6. 约束修正模块对控制量进行安全修正；
7. 执行后更新作业面地图和满斗率估计；
8. 当满斗率达到目标区间或负载风险升高时，切换至提升/卸载阶段。

#### 实施例二：带液压迟滞补偿的阶段策略控制

1. 采集历史状态和历史控制指令；
2. 通过时序编码器提取液压响应特征；
3. 将液压响应特征与作业面表示、满斗率估计和阶段编码融合；
4. 输出当前阶段的液压控制指令；
5. 经约束修正后驱动液压执行机构。

#### 实施例三：行为树安全管理

行为树设置安全节点、异常恢复节点和自动作业节点。安全节点优先级高于自动作业节点。当检测到越界、超深、传感器异常、执行机构饱和或人工接管时，行为树中断当前阶段策略，切换至安全停止、保守控制或人工接管。


#### 实施例四：完整数值型实施例——20吨级液压挖掘机非固定料堆满斗率稳定控制

本实施例给出完整的系统参数、满斗率估计公式、策略模型结构、训练流程、约束参数和评价指标，以验证本发明方案的可实施性和技术效果。

##### （1）硬件配置与作业场景

- 机型：20吨级液压挖掘机，动臂长度 5.5 m，斗杆长度 2.5 m；
- 铲斗：标称容量 $V_{capacity}$ = 0.91 m³，有效容量修正系数 $k_{eff}$ = 0.85，有效容量 $V_{eff}$ = 0.773 m³；
- 作业场景：不规则土堆，初始高度 1.2 m ～ 2.8 m，随挖掘循环持续变化，每循环后土堆形态不可预测；
- 深度传感器：RGB-D相机，安装于驾驶室顶部前方，帧率 15 fps，有效测距范围 0.5 m ～ 5.0 m，深度精度 ±3 mm（1 m处）；
- 控制频率：10 Hz；液压传感器采样频率：100 Hz（降采样至10 Hz输入策略）。

##### （2）作业面环境表示参数

深度图经坐标变换后生成局部高度图，具体参数如下：

- 覆盖区域：以铲斗末端投影点为中心，前方 3.2 m × 3.2 m 范围；
- 栅格分辨率：0.05 m/格，高度图尺寸 64 × 64 格；
- 高度值：相对地面参考平面的高度，范围 [-0.5 m, 3.5 m]，归一化至 [0, 1]；
- 更新频率：每控制步更新一次（10 Hz）；
- 历史缓存：保留最近 $n$ = 10 帧高度图差分用于体积估计。

##### （3）满斗率估计方法（体积差分法）

本实施例采用基于作业面高度图体积差分的满斗率估计方法：

设挖掘开始时刻 $t_0$ 的高度图为 $H_{t_0}$，当前时刻 $t$ 的高度图为 $H_t$，栅格面积为 $A_{cell}$ = 0.05 × 0.05 = 0.0025 m²，则当前累计挖出体积为：

$$V_{dug}(t) = A_{cell} \sum_{i,j} \maxigl(H_{t_0}(i,j) - H_t(i,j),\ 0igr)$$

$$\hat{r}_{fill}(t) = \min\!\left(rac{V_{dug}(t)}{V_{eff}},\ 1.0

动态修正：当动臂油缸压力 $p_{boom}$ 超过额定压力的 85%（即 $p_{boom}$ > 25.5 MPa，额定 30 MPa）时，对满斗率估计值施加过载修正系数 $k_{load}$ = 1.05，防止欠估计导致继续挖掘引发溢洒。

##### （4）阶段切换条件（含具体阈值）

| 切换方向 | 触发条件 |
|---|---|
| 复位 → 入土 | 铲斗末端与高度图最高点距离 ≤ 0.30 m，且铲斗位于目标作业区域水平范围内 |
| 入土 → 挖掘 | 铲斗末端深度超过作业面参考高度 ≥ 0.05 m，或斗杆油缸压力 > 15 MPa |
| **挖掘 → 提升**（核心联合特征B触发条件） | $\hat{r}_{fill}(t)$ ≥ 0.75（满斗率下界），或连续挖掘时长 > 4.0 s，或动臂油缸压力 > 28 MPa |
| 提升/回转 → 卸载 | 铲斗末端进入卸载目标区域（水平误差 ≤ 0.25 m，高度误差 ≤ 0.15 m） |
| 卸载 → 复位 | $\hat{r}_{fill}(t)$ < 0.10（卸载完成），且铲斗姿态完成倾翻动作 |
| 任意 → 安全停止 | 作业边界越界、超深超过 0.80 m、传感器连续丢帧 > 5 帧、执行机构饱和持续 > 0.5 s |

满斗率目标区间设定为 $[r_{low},\ r_{high}]$ = [0.75, 0.92]。

##### （5）阶段策略模型结构与输入维度

策略模型采用共享状态编码器 + 多阶段输出头结构，输入特征拼接方式如下：

```text
输入模块：
  ① 高度图分支：64×64×1 → Conv(8,3×3,s=1,ReLU) → Conv(16,3×3,s=2,ReLU)
                → Conv(32,3×3,s=2,ReLU) → Flatten → FC(128) → 128维
  ② 满斗率标量：[fill_ratio] → FC(16,ReLU) → 16维
  ③ 机械状态：[θ_boom, θ_arm, θ_bucket, ω_boom, ω_arm, ω_bucket, p_boom, p_arm,
               p_bucket, x_ee, y_ee, z_ee, phase_code(4维 one-hot)]
               共16维 → FC(64,ReLU) → 64维
  ④ 历史控制序列：[u_{t-10},...,u_{t-1}]，形状(10,3)
               → GRU(hidden=64) → 取最后时步输出 → 64维

拼接：[128 + 16 + 64 + 64] = 272维
        ↓
共享编码器：FC(256,ReLU) → FC(128,ReLU) → 128维融合特征 z_t

挖掘阶段输出头：FC(64,ReLU) → FC(3,Tanh) → [u_boom, u_arm, u_bucket] ∈ [-1,1]
（其余阶段输出头结构相同，参数独立）
```

总参数量约 **320K**，在嵌入式工控机（CPU: i7-8700T）上推理延迟约 **1.2 ms**，满足10 Hz控制周期要求。

##### （6）训练流程

**数据采集**：由熟练操作员在仿真环境（Isaac Sim，土堆体积场景随机化）和真实机器上各采集 1000 循环人工操作数据，共 2000 循环（约 24 万控制步），含阶段标签、控制指令、机械状态、高度图序列和满斗率标签。

**训练策略**：两阶段训练。

- **第一阶段（行为克隆预训练）**：
  - 损失函数：$\mathcal{L}_{BC} = \|u_{pred} - u_{expert}\|_2^2$
  - 批大小：256，学习率：$3 	imes 10^{-4}$（Adam优化器），训练 200 epoch；
  - 收敛后挖掘阶段策略在验证集上动作MSE ≤ 0.032。

- **第二阶段（离线强化学习微调，IQL算法）**：
  - 奖励函数：
    $$r_t = 5.0 \cdot \mathbf{1}[\hat{r}_{fill} \in [0.75, 0.92]] - 2.0 \cdot \max(\hat{r}_{fill} - 0.92,\ 0) - 3.0 \cdot \mathbf{1}[\hat{r}_{fill} < 0.60] - 0.1\|u_t - u_{t-1}\|_2$$
  - 折扣因子 $\gamma$ = 0.99，训练 500K 步，每 10K 步在仿真环境中评估一次满斗率命中率；
  - 微调后满斗率命中率相较预训练阶段提升约 11 个百分点。

##### （7）约束修正参数

| 约束类型 | 参数值 | 修正方式 |
|---|---|---|
| 水平作业边界（相对回转中心） | $x \in [-2.5,\ 2.5]$ m，$y \in [0.5,\ 4.5]$ m | 方向抑制：越界方向分量置零 |
| 最大挖掘深度 | 铲斗末端高度 $z_{ee} \geq -0.80$ m | 限幅：$u_{boom}$ 向上偏置 |
| 关节角度限制 | 动臂 [25°, 65°]，斗杆 [20°, 130°]，铲斗 [40°, 90°] | 限幅 |
| 关节角速度限制 | 动臂 ≤ 8°/s，斗杆 ≤ 12°/s，铲斗 ≤ 15°/s | 比例缩放 |
| 控制平滑约束 | $\|u_t - u_{t-1}\|_\infty \leq 0.15$ | 一阶低通滤波，$lpha$ = 0.3 |
| 动臂油缸压力 | $p_{boom} \leq 30$ MPa | 超限时切换至保守提升策略 |

##### （8）评价指标与对比结果

在真实挖掘机上进行 50 个连续挖掘循环测试，土堆初始方量约 80 m³，随循环减少。对比基线为固定轨迹规划+PID跟踪方案（现有典型方案）。

| 评价指标 | 本发明方案 | 基线（固定轨迹+PID） |
|---|---|---|
| 满斗率命中率（落入 [0.75, 0.92]） | **82%**（41/50循环） | 61%（31/50循环） |
| 平均满斗率 $ar{r}_{fill}$ | **0.83 ± 0.07** | 0.79 ± 0.14 |
| 欠装率（$r_{fill}$ < 0.60） | **4%**（2/50循环） | 12%（6/50循环） |
| 过载/溢洒率（$r_{fill}$ > 1.0） | **0%** | 3%（2/50循环，人工介入） |
| 安全介入次数（50循环内） | **2次** | 8次 |
| 单循环平均用时 | 18.3 s | 17.1 s（+1.2 s可接受） |

**结论**：在作业面形态持续变化的非固定场景下，本发明方案相比固定轨迹方案，满斗率命中率提升约 **21 个百分点**，多循环满斗率标准差从 0.14 降低至 0.07（降幅 50%），欠装率和安全介入次数均显著降低，验证了本发明方案在非固定场景下的有效性。

### 8. 有益效果

本发明具有以下效果：

1. 通过作业面环境表示和满斗率估计，使挖掘动作能够随土堆形态变化调整；
2. 通过 FSM/BT 阶段管理，将阶段切换逻辑与阶段内控制策略解耦；
3. 通过阶段策略模型，使入土、挖掘、提升、卸载等阶段采用不同控制目标；
4. 通过历史序列建模，适应液压系统迟滞、延迟和负载变化；
5. 通过约束修正模块，降低学习型策略直接控制液压执行机构的安全风险；
6. 通过满斗率目标和多循环稳定性评价，提高非固定场景下单斗装载稳定性；
7. 通过将液压负载状态作为阶段切换的触发条件，在铲斗遇硬质土体或切削阻力骤增时无需等待满斗率达标即可提前退出挖掘阶段，防止液压系统长时间憋压，保护液压元件；同时缩短无效切削时间，提升挖掘循环效率。

上述效果与传感器配置、训练数据、机型和作业环境有关，不限定为固定精度或固定性能指标。

## 9. 本发明的关键点和保护点

### 9.1 关键点

1. **作业面环境表示与满斗率估计的组合使用**  
   不是单纯做视觉识别或单纯做装载检测，而是把作业面形态表示和满斗率估计组合成控制闭环的前端。

2. **满斗率与液压负载共同构成作业状态闭环，参与阶段管理和阶段切换**  
   满斗率和液压负载均非事后评价指标，而是共同作为阶段切换条件和挖掘阶段控制输入：满斗率达标触发正常切换，液压负载超限触发保护性提前切换，防止长时间憋压，提升挖掘效率。

3. **FSM/BT 负责阶段切换，策略模型负责阶段内控制**  
   阶段管理与控制生成分工明确，便于工程部署和异常处理。

4. **挖掘阶段根据满斗率动态调整动作参数**  
   重点不在“挖不挖”，而在“从哪里挖、挖多深、何时收斗、何时切阶段”。

5. **不以连续轨迹规划和轨迹跟踪作为必要中间步骤，阶段策略直接输出液压执行控制量**  
   阶段策略模型根据作业面表示、满斗率估计、液压负载状态、机械状态和历史控制序列，直接生成动臂、斗杆和铲斗的液压执行控制量，无需经过"规划轨迹→计算跟踪误差→换算控制量"的中间过程。轨迹信息仅可作为辅助约束或参考输入。该特征与作业状态闭环联合构成本发明的核心区别技术特征，可有效规避传统轨迹规划类专利的覆盖，同时防止被拆分规避。

6. **历史序列建模液压迟滞**  
   通过历史状态与历史控制反映液压迟滞和复合动作耦合。

7. **约束修正安全层**  
   学习型策略输出必须经过安全修正后才能执行。

### 9.2 保护点

1. **系统保护点**  
   包含作业面表示模块、满斗率估计模块、阶段管理模块、阶段条件策略模块和约束修正模块的整体系统。

2. **方法保护点**  
   包含“获取作业面表示 -> 估计满斗率 -> FSM/BT 阶段管理 -> 阶段策略输出 -> 约束修正 -> 执行”的方法流程。

3. **阶段切换保护点**  
   以满斗率、目标深度、切削路径完成度、液压负载或安全状态触发阶段切换。

4. **挖掘阶段控制保护点**  
   在挖掘阶段根据作业面表示和满斗率估计结果调整入土点、切削深度、斗杆回收速度和收斗时机。

5. **直接控制保护点（核心联合特征A）**  
   阶段策略模型直接根据作业面环境表示、满斗率估计结果、机械状态和历史控制序列，生成动臂、斗杆和铲斗的液压执行控制量，不以连续轨迹规划和轨迹跟踪作为必要中间步骤；轨迹信息仅作为辅助约束或参考输入。

6. **作业状态闭环保护点（核心联合特征B）**  
   满斗率估计结果和液压负载状态共同作为：（1）挖掘阶段策略模型的输入，用于调整入土点、切削深度、斗杆回收速度或铲斗收斗时机；（2）由挖掘阶段向提升/卸载阶段切换的触发条件——满斗率达标时正常切换，液压负载超限时保护性提前切换。两者共同构成作业状态反馈闭环，区别于将满斗率仅用于事后评价、将液压负载仅用于安全限幅的现有方案；通过液压负载触发的提前切换，防止液压系统长时间憋压，保护液压元件并提升挖掘效率。

> **说明**：核心联合特征A与核心联合特征B共同构成本发明最强保护组合，审查或无效程序中须同时成立方可构成侵权，防止被分别规避。

7. **约束修正保护点**  
   对作业边界、最大深度、关节极限、液压负载和控制平滑性进行修正。

8. **训练保护点**  
   通过模仿学习、离线强化学习、仿真强化学习或组合训练获得策略模型。

## 二、权利要求书初稿方向

### 权利要求1：系统权利要求

一种基于作业状态闭环的液压挖掘机阶段条件直接控制系统，其特征在于，包括：

1. 作业面感知模块，用于获取挖掘前方区域的环境信息；
2. 作业面表示模块，用于根据所述环境信息生成局部高度图、占据栅格、点云特征或局部地形地图；
3. 机械状态采集模块，用于获取动臂、斗杆、铲斗的状态以及历史控制指令；
4. 满斗率估计模块，用于根据作业面表示、铲斗几何、铲斗姿态、历史切削路径、称重信息或液压负载中的至少一种估计当前装载量或满斗率；
5. 阶段管理模块，用于根据有限状态机、行为树或其组合确定当前作业阶段；
6. 阶段条件策略模块，用于根据当前作业阶段、作业面表示、机械状态、历史控制指令和满斗率估计结果生成液压执行机构的原始控制指令；
7. 约束修正模块，用于对所述原始控制指令进行安全约束修正；
8. 液压执行控制模块，用于根据修正后的控制指令驱动液压执行机构。

其中，所述系统满足以下两组核心联合特征：

**联合特征A（直接控制）**：所述阶段条件策略模块直接根据作业面环境表示、满斗率估计结果、机械状态和历史控制序列，生成动臂、斗杆和铲斗的液压执行控制量，不以连续轨迹规划和轨迹跟踪作为必要中间步骤，轨迹信息仅作为辅助约束或参考输入；

**联合特征B（作业状态闭环）**：所述满斗率估计模块的估计结果和所述机械状态采集模块获取的液压负载状态共同用于：（1）作为挖掘阶段策略模型的输入，用于调整入土点、切削深度、斗杆回收速度或铲斗收斗时机；（2）作为所述阶段管理模块由挖掘阶段向提升阶段或卸载阶段切换的触发条件——满斗率达标时正常切换，液压负载超限时保护性提前切换，防止液压系统长时间憋压并提升挖掘效率。

### 权利要求2：方法权利要求

一种基于作业状态闭环的液压挖掘机阶段条件直接控制方法，其特征在于，包括：

1. 获取挖掘前方区域的环境信息，并生成作业面环境表示；
2. 获取液压挖掘机机械状态和历史控制指令；
3. 根据作业面环境表示、铲斗几何、铲斗姿态、历史切削路径、称重信息或液压负载估计当前装载量或满斗率；
4. 通过有限状态机、行为树或其组合确定当前作业阶段，**其中满斗率估计结果和液压负载状态共同作为由挖掘阶段向提升阶段或卸载阶段切换的触发条件：满斗率达标时正常切换，液压负载超限时保护性提前切换**；

6. 在挖掘阶段，**根据作业面环境表示、机械状态、历史控制指令和满斗率估计结果，直接生成动臂、斗杆和铲斗的液压执行控制量，不以连续轨迹规划和轨迹跟踪作为必要中间步骤**；

8. 根据修正后的控制量驱动液压执行机构；
9. 执行后更新作业面环境表示和满斗率估计结果。

### 权利要求3：从属权利要求方向

可进一步限定（从属权利要求方向）：

2. 阶段管理模块包括有限状态机和行为树，行为树设置安全节点，安全节点优先级高于自动作业节点，用于安全停止、异常恢复和人工接管；

8. 策略模型通过模仿学习、离线强化学习、仿真强化学习或其组合训练获得，训练目标包括满斗率目标区间命中率和多循环满斗率稳定性。

## 三、实施与验证建议

建议优先验证最小闭环：

1. 使用深度相机或激光雷达生成局部高度图；
2. 采集人工挖掘数据，包含阶段标签、控制指令和满斗率标签；
3. 训练挖掘阶段策略，使其学习入土点、切削深度和收斗时机；
4. 使用 FSM/BT 管理阶段切换；
5. 使用约束修正模块限制越界、超深、过载和控制突变；
6. 以单斗满斗率目标区间命中率、多循环满斗率方差、安全接管次数作为主要评价指标。

本专利方案应聚焦于“非固定场景下基于作业面表示和满斗率估计的阶段条件液压控制”，不建议再扩展为通用无人挖掘机全场景控制方案。
