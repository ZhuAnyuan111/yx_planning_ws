3、背景技术（别人现在是怎么做的？）

挖掘机自动装车中"卸载点选在哪里"，现有技术主要六类：（1）固定点位；（2）人工指定；（3）满斗率/料位检测辅助（CN120122112A，仅计量不参与选点）；（4）轨迹约束点（CN111733918B）；（5）感知驱动卸载点序列规划（US6363632B1、CN109902857B，最接近现有技术）；（6）网格覆盖式预规划（CN114164877B，网格化+IK 到位+整车总重判满）。

存在的技术问题（缺点）

1）选点与可达域脱节：固定/人工不校验运动学可达；CN-1"安全卸载范围"仅几何约束、CN114164877B 的 IK 仅执行到位，停偏时选点仍可能不可达。
2）判满判据缺失或单一：深度直方图/整车总重均无点级判据，点云稀疏或尖峰噪点易误判。
3）单点失效即整体失败：均以单一感知源定终止，一次误判即提前终止或持续超装，无计数交叉校验。
4）布料顺序非闭环：预规划重复或按整车载荷%切换，非逐点遍历，易近端堆高、铲斗越料。
5）与执行层脱节：选点结果不直接衔接卸载轨迹。

4、发明内容（针对技术问题提出的技术方案）

待解决问题：1）停偏时保证卸载点运动学可达；2）给出稳定不抖动的点级判满；3）单一感知源误判时维持连续与安全；4）布料由远及近闭环；5）选点直接驱动轨迹、异常仍有可执行目标。

总体方案："可达域 ∩ 未满域驱动动态选点、以斗数双向保底兜底"。卸载点 = 候选点中同时满足 ①IK 可达、②点云双门限判未满、③布料顺序（自远及近遍历）当前轮到的点；任何情形受斗数双向保底约束。可达域（几何）、料面（感知）、斗数（计数）三源独立、交叉校验。

4.1 多机制联动关系（创造性主线 · 回应评审建议2）

评审指出"仅按装载进度动态调整卸载点"与 CN109902857B/CN114164877B 重合、作为唯一核心创新点偏弱。本发明创造性不落在"按进度选点"上位思想，而落在三源因果闭环 + 计数对感知反向否决：

  • 可达域（几何/IK）→ 约束"能去哪"：逐点逆解可解性决定可达集合 F 与边界 idx_far，并决定中位兜底点（硬约束前置）。
  • 感知（点云双门限）→ 定位"哪里还没满"：仅在 F 内、由远及近判满，感知结论受可达域裁剪。
  • 计数（斗数）→ 独立第二判据，对感知行使否决/终止权：LoadNums≤MinLoadNum 且感知全判满时不采信感知（反向否决，防误停）；LoadNums>MaxLoadNum 时强制终止（防超载）。
  • 交叉兜底：感知失效→load_num 三段式；可达域不足→两级判定/重新停靠；计数越界→中位点收尾。任一单源异常仍输出可执行点（永不无解）。
联动命题（形式化）：设可达域 R、未满域 U（感知）、计数约束 C，则 p* = argfirst_{i∈R, 由远及近}(i∈U)，且经 C 修正：C 可在 U=∅ 时否决"满"结论（下限）、或在计数越界时终止（上限）。三者的耦合与相互否决是区别于"单一感知源判满即终止"现有技术（CN-1/CN114164877B/US12216018B2）的实质特征。

5.1 步骤 1：候选点生成

基线（UP.m，等距）：s_i = linspace(-(L/2+d_start), (L/2+d_end), N), i=1..N
　p_i = ( c_x + s_i·cosψ,　c_y + s_i·sinψ,　c_z + H/2 + h_up )　　（ψ=矿卡航向角, c=车厢中心）
优选改进（unloadP.m V2.0，远密近疏）：t_raw=(i-1)/(N-1),　t = 1 - (1 - t_raw)^k, k=2.5
　p_i = p_near + t·(p_far - p_near)　（z 取 p_near_z）

动机：布料由远及近，远端最先触及可达域边界，加密远端提高 idx_far 判定精度。等距与远密近疏均落入权利要求①。

5.2 步骤 2：逐点 IK 可解性筛选，定可达域边界

主解（给定姿态角 α）：swing = mod(atan2d(y,x)+180, 360)；x_1=(x-b_x·cos·)/cos·（含 swing=±90° 特例）, z_1=z-b_z
　x_3=x_1-L_k'·cosα, z_3=z_1-L_k'·sinα（L_k'=L_k·bucket_bias）；l_5=√(x_1²+z_1²), l_6=√(x_3²+z_3²)
　cosβ=(l_5²+l_6²-L_k'²)/(2 l_5 l_6),　cosα_=(L_b²+l_6²-L_a²)/(2 L_b l_6)
　boom=atan2d(z_1,x_1)+acosd(cosβ)+acosd(cosα_)；arm=acosd((L_b²+L_a²-l_6²)/(2 L_b L_a))-180；bucket=α-boom-arm
保底解（主解失败，固定斗角 β_k=30°/25°）：关节-铲斗联合逆解（FV/CV + 余弦定理），同过可解性与限位判据
可达域：F={i | feasibility_i=1}；idx_near=min F, idx_far=max F（可达域边界）；mid=F(round(|F|/2))

下限保底全部判满（∄i:SoilFullInPoint_i=0）且 LoadNums ≤ MinLoadNum不采信"全满"结论，取 mid 继续，TruckFullFlag=0防感知误判提前终止
真满收尾全部判满且 MinLoadNum < LoadNums ≤ MaxLoadNumTruckFullFlag=1，取 mid 收尾正常装满
正常存在未满点保持步骤 5 所选点—
任何 return 路径 unloadPoint 均有值（mid 兜底）→ 系统永不无解。 ⑤为全案最强、最干净区别特征：四篇最接近文献均单一感知源判满即终止，无"计数反向否决感知结论"逻辑。

5.7 步骤 7：调度执行与回转圆入厢衔接点

调度状态机（multi_unload_scheduler.m）：loadingFlag 触发→选点→由远及近逐点执行；dump_done_flag 触发复位、reset_done_flag 触发下一次卸载
入厢衔接（calc_entry_point_circle_strategy）：dig_end=FK(start_joint) 齿尖 XY；R1=‖dig_end‖, R2=‖unloadPoint_xy‖
　R = R_coff·R1 + (1−R_coff)·R2（R_coff=0.5）；R<1e−6 → flag=0 退化，入厢点=unloadPoint_xy
　圆∩车厢矩形（局部系 L×W）四边：有交点→沿 rot_dir 取与 dig_end swing 角差最小交点（flag=1）；无交点→最近边投影点（flag=2）

6、本发明的优点（含量化效果）

1）选出即必然可达：卸载点必取自 F（IK 可解+限位余量 δ），构造性保证；停偏时在缩小后可达域内选点。
2）布料与实际料面闭环：双门限判满直接驱动下一点，先堆高区自动跳过，避免堆高/撒料/越料。
3）双重门限拦截两类误判：门限1 防稀疏、门限2（均值）防尖峰，方向相反；跨轮继承防翻转。
4）感知与计数互为冗余：下限保底防误停、上限保底防超载；点云不可用降级三段式。
5）永不无解 + 选点与轨迹一体化衔接：异常路径输出中位可达点；同时输出入厢衔接点，无缝对接下游轨迹。

7、本发明的关键点和保护点（领导最关注点）

独立权利要求 1（方法）必要技术特征：

① 候选点生成：沿车厢中心线生成 N 个候选点，呈远密近疏非线性分布（优选 t=1-(1-t_raw)^k, k>1），按矿卡实测位姿变换至挖机坐标系；
② 可达域确定：对候选点逐一求逆运动学并以逆解可解性作为准入条件（主解+固定斗角保底解），按带安全余量 δ 的关节限位校验，得可达集合 F 及可达域边界 idx_far；
③ 双重门限判满：以沿车头偏移的预设圆域内点云判定——点数大于门限时算局部平均高度，不大于 z_plane+Δh_full 判未满、否则已满；点数不大于门限时判未满（三要素完整）；
④ 由远及近遍历：自 idx_far 向 idx_near 遍历，取首个未满可达点为当前卸载点并输出关节角；
⑤ 斗数双向保底（第一区别特征锚点）：LoadNums>MaxLoadNum 强制结束并取中位点执行最后一斗；全部判满但 LoadNums≤MinLoadNum 时不采信已满判定、取中位点继续。

从属保护点（退路）：⑥满载跨轮继承；⑦检测圆域限定（车头偏移+半径+算术均值）；⑧分布函数式与 N/k 优选值；⑨IK 双重筛选（α 主解+β_k 保底+δ 余量）；⑩矿卡可达两级判定（idx_far vs 0.5N + 阈值位装满豁免）；⑪遍历毕全满且斗数大于下限时判整车装满；⑫降级 load_num 三段式；⑬中位点全兜底；⑭多点多次调度状态机；⑮回转圆入厢衔接点；⑯系统权利要求（七模块）与计算机可读存储介质；⑰执行层异常处理链（段确认帧/超时推进/高度门控重试/clamp 中止/错误码 1-2-3）作为系统从属。

布局说明：③④⑤为核心区别且互为因果（判满→遍历方向→保底校验），以 4.1 三源联动/反向否决为创造性主线；⑤最强最干净，置于论证最前；②措辞收紧为"以逆解可解性筛选候选点并确定可达域边界"。不保护"感知料面→选卸载点"上位思想（已被 CN109902857B/US6363632B1 公开）。

8、替代方式

1）N=21→N≥5 任意值；分布函数→任意远密近疏函数（指数/分段线性），退化为均匀分布亦落入主线；2）候选线→中心线两侧多排；高度→按车型配置；3）IK 解析解→数值迭代/几何法；β_k 可在 20°~30° 取值；4）进度评估→点云双门限+load_num 组合，或车厢称重/料位雷达；门限→中值高度/高度方差/按物料类型切换；5）布料顺序→由近及远（短回转）/交替；Max/Min 斗数→按额定方量换算；6）调度→任意 K×M 或单点单次退化；入厢衔接→直接取卸载点/固定半径圆弧；7）场景→装载机、电铲装卡车等。
