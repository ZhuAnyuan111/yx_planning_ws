# 专利技术交底书

## 一种考虑液压特性的挖掘机卸载轨迹规划方法与系统

---

## 一、技术领域

本发明涉及工程机械自动化技术领域，具体涉及一种考虑液压系统非线性特性的挖掘机自动卸载轨迹规划方法与系统，适用于无人挖掘机在矿山、土方工程等场景下的自动化卸载作业。

---

## 二、背景技术

### 2.1 现有技术

挖掘机卸载作业是无人挖掘机自主作业的关键环节。传统卸载轨迹规划方法主要包括：

**（1）笛卡尔空间轨迹规划 + 时间表驱动**

在笛卡尔空间预规划完整轨迹（铲斗齿尖路径），按时间表驱动执行。该方法假设液压系统能够精确跟踪指令，但实际液压系统存在 50-200ms 延迟、死区、流量饱和、负载依赖等非线性特性，导致实际关节响应滞后于参考指令，全程相位漂移，终点到达时刻不可预测。

**（2）在线重规划**

每步重新规划轨迹，适应性强。但计算量大，实时性难以保证，且可能因液压振荡导致轨迹不稳定。

**（3）模型预测控制（MPC）**

基于模型预测未来状态，求解最优控制序列。但依赖精确的液压模型，而液压非线性难以准确建模，模型失配时性能急剧下降。

**（4）自适应控制**

在线调整控制参数以适应参数变化。但不解决时间不确定性问题，液压延迟导致的相位漂移无法通过自适应控制消除。

### 2.2 现有技术的缺点

现有技术的共同问题是：**未显式考虑液压系统的非线性特性**，将液压延迟/死区/饱和等视为"跟踪误差"，依赖伺服系统补偿。但液压延迟是物理本质，伺服无法完全补偿，导致：

1. **时间不确定性无法预测**：液压延迟导致"何时到达终点"不可预测，时间表驱动失效；
2. **误差跨段累积**：前段跟踪误差会污染后续轨迹，终点几何意义（入厢点、卸载点）被污染；
3. **物理约束被忽视**：段终点关节角到位 ≠ 物理允许（如铲斗高度不够跨越卡车），可能导致铲斗越界事故；
4. **参数调优困难**：容差、速度等参数依赖经验，缺乏实测依据，不同工况需重新调优。

---

## 三、发明目的

本发明的目的是提供一种考虑液压特性的挖掘机卸载轨迹规划方法与系统，解决现有技术未显式考虑液压非线性特性导致的时间不确定性、误差累积、物理约束忽视等问题，实现安全可靠的自动卸载作业。

具体要解决的技术问题：

1. 如何将液压延迟导致的时间不确定性转化为可控的"进度快慢"，而非"跟踪对错"？
2. 如何保证终点几何意义（入厢点、卸载点）不被液压误差污染？
3. 如何在段终点关节角到位但物理条件不满足时（如铲斗高度不够），阻止段推进并自动补偿？
4. 如何将液压特性显式编码到轨迹规划参数中，使参数调优有据可依？

---

## 四、技术方案

### 4.1 核心思想：终点锚定

本发明的核心思想是**"终点锚定"**：段终点（航路点）是整条轨迹中唯一不可妥协的几何锚点，所有液压不确定性（延迟、非线性、振荡）均被约束在"从当前实际起点到固定终点"的单段内吸收。终点本身通过四层机制适配液压非线性：

1. **终点几何固定，起点跟随现实**（误差不跨段累积）
2. **终点速度整形**（门控点强制归零）
3. **软到达判定**（容差 + 连续帧确认 + 超时兜底）
4. **物理安全门控**（FK 高度判定 + boost 微段）

### 4.2 方法步骤

#### 步骤 1：航路点生成（离线/激活时一次性计算）

生成 N 个关键航路点（关节角，rad），N ≥ 3，优选 N = 6：

- **WP1**：挖掘终止点（起点，姿态角修正）
- **WP2**：动臂提升点（swing/arm/bucket 保持，仅 boom 提升）
- **WP3**：中间过渡点（swing 走一半，boom/arm 按系数混合）
- **WP4**：厢上过渡点（xy 由回转圆策略决定，z=unload_z+height_bias，IK 求解）
- **WP5**：除铲斗到位（swing 到位，boom/arm 按 P5 系数混合到 unload）
- **WP6**：终点（unload_joint 完整）

航路点生成后，计算各段预期时长 `segment_times_[i]`（基于各段主导关节速度）。

#### 步骤 2：在线分段重规划（每段执行前实时计算）

对当前段 `seg_idx`（0 到 N-2），执行在线重规划：

**（1）起点取实际反馈**：`seg_start = current_joint_`（消除累积误差）

**（2）终点取固定航路点**：`seg_end = waypoints_[seg_idx + 1]`（几何锚点不可妥协）

**（3）将起点 swing 展开到与目标同一周期**（处理 0°/360° 跨越）

**（4）计算段时间**：基于实际剩余角度差，取各关节最大时间

```
max_time = max(
  swing_diff / wp_vel_swing,
  boom_diff / wp_vel_boom,
  arm_diff / wp_vel_arm,
  bkt_diff / wp_vel_bkt
)
```

**（5）确定起点/终点切线**：

- 起点切线 `v_start`：从反馈估计实际速度（双路独立历史，最近 3 帧首末差分，swing 需环绕归一化）
- 终点切线 `v_end`：从预计算的航路点切线取（Catmull-Rom，门控点强制为 0）

**（6）曲线插值生成局部轨迹**：

```
seg_trajectory = InterpolateSegmentWithTangents(
  seg_start, seg_end, v_start, v_end, max_time, dt
)
```

所述曲线插值方法包括 Hermite 插值、B 样条插值、贝塞尔插值、多项式插值中的任一种。

#### 步骤 3：反馈驱动段推进（实时判定）

对当前段执行过程，实时判定段推进结果：

**（1）主判定：主导关节误差 + 连续帧确认**

```
seg_err = ComputeSegError(seg_idx)  // 仅检查该段指定的主导关节
if (seg_err <= tolerance && confirm_count >= N) {
  return kComplete;  // 段完成
}
```

各段主导关节（N=6 时）：
- seg0（WP1→WP2）：boom
- seg1（WP2→WP3）：swing
- seg2（WP3→WP4）：swing + 高度门控
- seg3（WP4→WP5）：swing
- seg4（WP5→WP6）：max(arm, bucket)

**（2）兜底：超时处理**

```
if (seg_elapsed > seg_timeout) {
  if (seg_idx == 2 && height_gate && !IsBucketAboveTruck()) {
    return kEnterGate;  // 转入高度门控
  }
  return kComplete;  // 强制推进
}
```

超时基准取"标称段时长"与"在线实际规划段时长"的较大者，防止反馈残差大时误判正常段超时。

#### 步骤 4：高度门控与 boost 机制（物理安全层）

当目标段超时且铲斗位置未满足安全条件时，转入安全门控：

**（1）门控等待**：锁存当前姿态 `gate_hold_cmd_`，恒定发布（防止液压保压沉降被逐帧追认）

**（2）门控超时**：自动追加提升重试（boost 微段）

```
boost_target.boom = min(current_boom + gate_boost_boom_deg, boom_upper_limit)
boost_target.arm = current_arm - delta_boom  // arm 反向联动保姿态
```

**（3）boost 完成/超时**：回到门控等待，重新判定高度

**（4）boost 次数耗尽**：终止卸载，上报 error_code=3

**安全条件**：铲斗高度大于卡车上表面高度加预设余量。

#### 步骤 5：状态上报与可视化

- 完成标志：`/Sys_RUn_FlagUnloadExcuteFinish`（latched），激活时 0，结束（含正常/超时/门控失败/撤销）时 1
- 功能安全状态字：`/UT_PlanningPulse_topic`（心跳 | 模块 ID | 错误码），error_code=0/1/2/3 分别表示正常/卡车不可达/规划失败/执行中止
- 可视化：卡车包络、臂架线段、回转圆、轨迹折线、状态文本（RViz 实时联调）

### 4.3 系统架构

本发明系统包括：

1. **航路点生成模块**：生成 N 个关键航路点及段时间
2. **在线重规划模块**：每段执行前实时计算局部轨迹
3. **段推进判定模块**：反馈驱动 + 超时兜底
4. **安全门控模块**：FK 高度判定 + boost 机制
5. **状态上报模块**：完成标志、功能安全状态字、可视化
6. **液压参数辨识模块**（可选）：在线估计延迟/带宽，动态调整参数

## 五、有益效果

与现有技术相比，本发明具有以下优点：

1. **终点几何意义永不漂移**：终点锚定思想保证入厢点、卸载点等关键几何锚点不被液压误差污染，误差不跨段累积；

2. **对液压非线性具有鲁棒性**：把液压时间不确定性转化为"进度快慢"，放弃预测"何时到达"，转而专注"到了没有"，系统对液压延迟/死区/饱和具有天然鲁棒性；

3. **物理约束优先于时间约束**：高度门控 + boost 机制保证铲斗必须高于卡车才允许跨越，避免铲斗越界事故；

4. **参数调优有据可依**：液压特性（延迟、带宽、饱和）被显式编码到段速度、容差、门控余量等参数中，参数调优从"经验试错"升级为"实测回填"；

5. **实机验证闭环**：FK 标定 + 底层跟踪带宽验证 + 参数回填，形成"测量-回填-验证"闭环，保证方案在实机上可落地、可复现。

## 六、具体实施方式

### 6.1 实施例 1：WP3→WP4 段（seg2）执行过程

**场景**：挖掘机从挖掘点回转到厢上过渡点，需跨越卡车上方。

**步骤**：

1. 航路点生成：WP3（swing=180°, boom=30°, arm=-20°, bucket=10°），WP4（swing=200°, boom=35°, arm=-15°, bucket=5°）
2. 在线重规划：起点取实际反馈（swing=179°, boom=29°, arm=-19°, bucket=11°），终点取 WP4
3. 段时间计算：swing_diff=21°, boom_diff=6°, max_time = max(21/15, 6/8) = 1.4s
4. Hermite 插值：生成 14 帧轨迹（10Hz）
5. 段推进判定：仅检查 swing 误差，容差 5°，连续 3 帧确认
6. 高度门控：seg2 完成后检查铲斗高度，若 `bucket_height < truck_top_height + margin`，转入门控等待
7. 门控超时（4s）：自动 boost，boom 提升 3°，arm 反向联动 -3°
8. boost 完成：回到门控等待，重新判定高度
9. 高度达标：推进到 seg3

### 6.2 实施例 2：液压延迟场景

**场景**：液压延迟 150ms，指令到达终点时反馈仍滞后 5°。

**传统方案**：按时间表执行，150ms 后指令已切换到下一段，反馈滞后导致误差累积。

**本方案**：
1. 段推进判定：swing 误差 5° > 容差 5°，未确认
2. 超时兜底：seg_elapsed = 1.4s × 2.0 = 2.8s，未超时
3. 继续等待：150ms 后反馈到达，误差 0° < 5°，连续 3 帧确认
4. 段完成：推进到下一段，起点取新反馈，误差不跨段累积

## 八、权利要求书

### 独立权利要求 1（方法，最宽保护范围）

一种考虑液压特性的挖掘机卸载轨迹规划方法，其特征在于，包括以下步骤：

**（1）航路点生成**：生成 N 个关键航路点，N ≥ 3，所述航路点包括起点、至少一个中间过渡点和终点，所述航路点为关节角；

**（2）在线分段重规划**：将所述 N 个航路点划分为 N-1 段，对当前执行段，起点取实际关节角反馈，终点取固定航路点，基于实际剩余角度差计算段时间，使用曲线插值方法生成局部轨迹；

**（3）反馈驱动段推进**：实时计算当前段关节误差，当误差小于预设容差且连续 N 帧确认时，判定段完成并推进到下一段；当段执行时间超过超时阈值时，强制推进或转入安全门控；

**（4）安全门控**：当目标段超时且铲斗位置未满足预设安全条件时，锁存当前姿态，等待铲斗位置达标或自动追加提升重试，超过最大重试次数则终止卸载。

### 从属权利要求 2（航路点具体化）

根据权利要求 1 所述的方法，其特征在于，N = 6，所述 6 个航路点包括：

- WP1：挖掘终止点（起点）
- WP2：动臂提升点
- WP3：中间过渡点
- WP4：厢上过渡点
- WP5：除铲斗到位点
- WP6：卸载终点

### 从属权利要求 3（插值方法具体化）

根据权利要求 1 所述的方法，其特征在于，所述曲线插值方法包括 Hermite 插值、B 样条插值、贝塞尔插值、多项式插值中的任一种，所述插值的起点切线由反馈速度估计得到，终点切线由预计算的航路点切线得到。

### 从属权利要求 4（段完成判定具体化）

根据权利要求 1 所述的方法，其特征在于，所述步骤（3）中，各段指定不同的主导关节进行误差判定：

- 段 0：仅判断动臂角度误差
- 段 1：仅判断回转角度误差
- 段 2：判断回转角度误差 + 安全门控
- 段 3：仅判断回转角度误差
- 段 4：判断斗杆角度误差与铲斗角度误差的最大值

### 从属权利要求 5（超时基准具体化）

根据权利要求 1 所述的方法，其特征在于，所述步骤（3）中，超时阈值取标称段时长与在线实际规划段时长的较大者，防止反馈残差大时误判正常段超时。

### 从属权利要求 6（安全门控具体化）

根据权利要求 1 所述的方法，其特征在于，所述步骤（4）中：

- 安全条件包括铲斗高度大于卡车上表面高度加预设余量
- 提升重试包括动臂提升和斗杆反向联动，保持铲斗姿态
- 锁存当前姿态防止液压保压沉降被逐帧追认

### 独立权利要求 7（系统，与方法对应）

一种考虑液压特性的挖掘机卸载轨迹规划系统，其特征在于，包括：

- **航路点生成模块**：生成 N 个关键航路点，N ≥ 3，所述航路点为关节角
- **在线重规划模块**：对当前执行段，起点取实际关节角反馈，终点取固定航路点，使用曲线插值方法生成局部轨迹
- **段推进判定模块**：实时计算关节误差，反馈驱动段推进 + 超时兜底
- **安全门控模块**：当目标段超时且铲斗位置未满足安全条件时，锁存姿态 + 提升重试
- **状态上报模块**：发布完成标志、功能安全状态字

### 独立权利要求 8（计算机可读存储介质）

一种计算机可读存储介质，其上存储有计算机程序，其特征在于，所述程序被处理器执行时实现权利要求 1-6 中任一项所述的方法。

## 九、摘要

本发明公开了一种考虑液压特性的挖掘机卸载轨迹规划方法与系统。核心思想是"终点锚定"：段终点是整条轨迹中唯一不可妥协的几何锚点，所有液压不确定性均被约束在"从当前实际起点到固定终点"的单段内吸收。通过四层机制（终点几何固定、速度整形、软到达判定、物理安全门控）适配液压非线性，实现安全可靠的自动卸载作业。本发明解决了现有技术未显式考虑液压非线性特性导致的时间不确定性、误差累积、物理约束忽视等问题，具有实机可落地、参数可调优、方案可复现的优点。
