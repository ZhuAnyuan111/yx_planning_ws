# 挖掘机卸载轨迹控制方案对比

## 1. 系统背景

### 1.1 轨迹规划特点

- **轨迹形式**：关节空间位置轨迹（WP1-WP6 航路点）
- **在线重规划**：每段起点取实时关节反馈，Hermite 插值到下一航路点
- **段完成判定**：位置容差 + 连续帧确认 + 超时兜底
- **执行机构**：液压缸（非线性、负载敏感、响应延迟 50-200ms）

### 1.2 控制需求

| 需求 | 描述 |
|:---|:---|
| 位置精度 | 卸载点定位误差 < 5° |
| 运动平滑 | 防洒料、防液压冲击 |
| 抗扰动 | 负载变化（满载/空载）、地面颠簸 |
| 段间过渡 | 段切换时控制量无突变 |
| 响应速度 | 跟踪规划速度（5-15°/s） |

---

## 2. 方案一：纯位置环控制

### 2.1 控制结构

```
位置指令 q_cmd ──► [位置控制器] ──► 阀/电流指令 ──► 液压缸
                        │
                        ▼
                    位置反馈 q_fb
                    
误差 e = q_cmd - q_fb
控制量 u = Kp × e [+ Ki × ∫e dt + Kd × de/dt]
```

### 2.2 优点

| 优点 | 说明 |
|:---|:---|
| 结构简单 | 单环控制，参数少，易实现 |
| 位置精度高 | 位置闭环，稳态误差小 |
| 与规划直接对接 | 规划输出位置，直接作为指令 |
| 抗稳态扰动 | 积分项可消除稳态误差 |

### 2.3 缺点

| 缺点 | 说明 | 影响 |
|:---|:---|:---|
| 段切换跳变敏感 | 位置指令跳变 Δθ → 控制量突变 Kp×Δθ | 液压冲击、机械抖动 |
| 抗扰动能力弱 | 负载变化需等位置偏差积累后才补偿 | 满载时跟踪滞后 |
| 速度不直接控制 | 速度由位置微分间接得到 | 高速时易过冲 |
| 液压非线性影响大 | 流量-压力非线性难以补偿 | 低速爬行、高速振荡 |

### 2.4 段切换问题分析

```
段 n 完成时刻：
  位置指令：q_cmd = q_wp_n（航路点）
  实际位置：q_fb = q_wp_n - e（存在跟踪误差 e）

段 n+1 开始时刻（若取实时位置为起点）：
  位置指令跳变：q_cmd_new = q_fb = q_wp_n - e
  跳变量：Δq = -e
  控制量突变：Δu = Kp × e

典型数值：
  e = 2-5°（容差范围内）
  Kp = 10 → Δu = 20-50（控制量单位）
```

### 2.5 实现方案

#### 2.5.1 基础实现

```cpp
// 位置环控制器
class PositionController {
 public:
  struct Params {
    double kp = 10.0;       // 比例增益
    double ki = 0.5;        // 积分增益
    double kd = 0.1;        // 微分增益
    double integral_limit = 50.0;   // 积分限幅
    double output_limit = 100.0;    // 输出限幅
  };
  
  double Compute(double q_cmd, double q_fb, double dt) {
    double error = q_cmd - q_fb;
    
    // 积分抗饱和
    integral_ += error * dt;
    integral_ = clamp(integral_, -params_.integral_limit, params_.integral_limit);
    
    // 微分（对反馈微分，避免指令跳变影响）
    double derivative = -(q_fb - q_fb_last_) / dt;
    q_fb_last_ = q_fb;
    
    // PID 输出
    double output = params_.kp * error + params_.ki * integral_ + params_.kd * derivative;
    return clamp(output, -params_.output_limit, params_.output_limit);
  }
  
 private:
  Params params_;
  double integral_ = 0.0;
  double q_fb_last_ = 0.0;
};
```

#### 2.5.2 段切换保护（推荐添加）

```cpp
// 段起点位置限幅，防止指令跳变
class SegmentTransitionGuard {
 public:
  // 限制段间起点跳变量
  kinematics::JointState LimitStartJump(
      const kinematics::JointState& q_actual,    // 实时位置
      const kinematics::JointState& q_ref_end,   // 上一段参考终点
      double max_jump_deg) {                      // 最大允许跳变
    
    kinematics::JointState q_start = q_actual;
    
    // 对每个关节限幅
    q_start.boom = ClampToRange(q_actual.boom, q_ref_end.boom, max_jump_deg);
    q_start.arm = ClampToRange(q_actual.arm, q_ref_end.arm, max_jump_deg);
    q_start.bucket = ClampToRange(q_actual.bucket, q_ref_end.bucket, max_jump_deg);
    // swing 需处理角度环绕
    q_start.swing = ClampSwingToRange(q_actual.swing, q_ref_end.swing, max_jump_deg);
    
    return q_start;
  }
  
 private:
  double ClampToRange(double actual, double ref, double max_dev) {
    double diff = actual - ref;
    if (std::abs(diff) > max_dev) {
      return ref + std::copysign(max_dev, diff);
    }
    return actual;
  }
};
```

### 2.6 参数整定建议

| 参数 | 建议范围 | 说明 |
|:---|:---|:---|
| Kp | 5-15 | 大 → 响应快但易振荡 |
| Ki | 0.1-1.0 | 消除稳态误差，过大导致积分饱和 |
| Kd | 0.05-0.5 | 抑制振荡，过大放大噪声 |
| 段跳变限幅 | 2-5° | 平衡精度与平滑 |

## 3. 方案二：纯速度环控制

### 3.1 控制结构

```
速度指令 v_cmd ──► [速度控制器] ──► 阀/电流指令 ──► 液压缸
                        │
                        ▼
                    速度反馈 v_fb
                    
误差 e = v_cmd - v_fb
控制量 u = Kv × e [+ Ki_v × ∫e dt]
```

### 3.2 位置指令转速度指令

```cpp
// 位置轨迹 → 速度指令（需外部位置环或轨迹微分）
double PositionToVelocity(double q_cmd, double q_fb, double kp_pos) {
  // 简单位置外环：速度指令 = 位置误差 × 增益
  return kp_pos * (q_cmd - q_fb);
}

// 或轨迹微分（不推荐，噪声大）
double TrajectoryDifferentiation(double q_cmd, double q_cmd_last, double dt) {
  return (q_cmd - q_cmd_last) / dt;  // 需要低通滤波
}
```

### 3.3 优点

| 优点 | 说明 |
|:---|:---|
| 段切换平滑 | 位置跳变不直接导致控制量突变 |
| 速度控制直接 | 适合速度规划为主的场景 |
| 抗位置扰动 | 位置偏差不会立即反映到控制量 |
| 液压流量匹配 | 速度指令可直接对应阀流量 |

### 3.4 缺点

| 缺点 | 说明 | 影响 |
|:---|:---|:---|
| 位置精度低 | 无位置闭环，依赖积分 | 稳态位置漂移 |
| 需位置外环 | 要跟踪位置轨迹必须加位置外环 | 实际变成串级控制 |
| 抗负载扰动弱 | 负载变化导致速度变化，需时间补偿 | 满载时速度下降 |
| 终点精度难保证 | 位置积分误差累积 | 卸载点定位不准 |

### 3.5 段切换行为分析

```
段切换时：
  位置指令跳变：Δq
  速度指令变化：Δv = kp_pos × Δq（若用位置外环）
  
  相比纯位置环：
    控制量变化 = Kv × Δv = Kv × kp_pos × Δq
    
  若 Kv × kp_pos < Kp_position，则控制量突变更小
```

### 3.6 实现方案

```cpp
// 速度环控制器
class VelocityController {
 public:
  struct Params {
    double kv = 5.0;        // 速度比例增益
    double ki_v = 1.0;      // 速度积分增益
    double output_limit = 100.0;
  };
  
  double Compute(double v_cmd, double v_fb, double dt) {
    double error = v_cmd - v_fb;
    
    integral_ += error * dt;
    integral_ = clamp(integral_, -50.0, 50.0);
    
    double output = params_.kv * error + params_.ki_v * integral_;
    return clamp(output, -params_.output_limit, params_.output_limit);
  }
  
 private:
  Params params_;
  double integral_ = 0.0;
};

// 轨迹跟踪器（位置 → 速度）
class TrajectoryTracker {
 public:
  double ComputeVelocityCommand(double q_cmd, double q_fb) {
    // 简单位置外环
    double pos_error = q_cmd - q_fb;
    double v_cmd = kp_pos_ * pos_error;
    
    // 速度限幅（关键：防止位置跳变导致速度指令过大）
    return clamp(v_cmd, -v_max_, v_max_);
  }
  
 private:
  double kp_pos_ = 2.0;   // 位置环增益
  double v_max_ = 20.0;   // 速度限幅 (deg/s)
};
```

### 3.7 适用场景

- 对位置精度要求不高（±10° 可接受）
- 主要关注速度平滑性
- 有独立的位置校准机制

## 4. 方案三：位置外环 + 速度内环（串级控制）【推荐】

### 4.1 控制结构

```
位置指令 q_cmd ──► [位置外环] ──► 速度指令 v_cmd ──► [速度内环] ──► 阀指令 ──► 液压缸
                        │                                │
                        ▼                                ▼
                    位置反馈 q_fb                    速度反馈 v_fb
                    
位置外环：v_cmd = Kp_pos × (q_cmd - q_fb) [+ 前馈]
速度内环：u = Kv × (v_cmd - v_fb) [+ Ki_v × ∫]
```

### 4.2 优点

| 优点 | 说明 |
|:---|:---|
| 位置精度高 | 位置外环保证终点精度 |
| 速度平滑 | 速度内环平滑速度指令 |
| 抗扰动强 | 速度内环快速补偿负载扰动 |
| 段切换鲁棒 | 位置跳变被速度限幅吸收 |
| 液压适配好 | 速度内环直接控制阀流量 |
| 参数解耦 | 位置环/速度环可独立整定 |

### 4.3 缺点

| 缺点 | 说明 |
|:---|:---|
| 结构复杂 | 双环控制，参数多 |
| 需速度反馈 | 需要编码器微分或观测器 |
| 整定难度高 | 两环增益需协调 |
| 延迟敏感 | 速度反馈延迟影响内环稳定性 |

### 4.4 段切换行为分析

```
段切换时：
  位置指令跳变：Δq
  
位置外环响应：
  速度指令变化：Δv_cmd = Kp_pos × Δq
  速度限幅：v_cmd = clamp(Δv_cmd, -v_max, v_max)
  
速度内环响应：
  控制量变化：Δu = Kv × (v_cmd_limited - v_fb)
  
关键：速度限幅 v_max 限制了控制量突变的上限
  最大控制量变化 ≤ Kv × v_max
```

**与纯位置环对比**：
```
纯位置环：Δu = Kp × Δq（无上限）
串级控制：Δu ≤ Kv × v_max（有上限）
```

### 4.5 实现方案

#### 4.5.1 完整控制器

```cpp
// 串级控制器
class CascadeController {
 public:
  struct Params {
    // 位置外环
    double kp_pos = 2.0;        // 位置增益 (1/s)
    double v_max = 20.0;        // 速度限幅 (deg/s)
    double pos_ff_gain = 0.8;   // 位置前馈增益
    
    // 速度内环
    double kv = 8.0;            // 速度比例增益
    double ki_v = 2.0;          // 速度积分增益
    double integral_limit = 50.0;
    double output_limit = 100.0;
  };
  
  double Compute(double q_cmd, double q_fb, double v_fb, double dt,
                 double v_ff = 0.0) {
    // ===== 位置外环 =====
    double pos_error = q_cmd - q_fb;
    double v_cmd = params_.kp_pos * pos_error;
    
    // 前馈：规划速度直接叠加
    v_cmd += params_.pos_ff_gain * v_ff;
    
    // 速度限幅（关键：防止位置跳变导致速度指令突变）
    v_cmd = clamp(v_cmd, -params_.v_max, params_.v_max);
    
    // ===== 速度内环 =====
    double vel_error = v_cmd - v_fb;
    
    vel_integral_ += vel_error * dt;
    vel_integral_ = clamp(vel_integral_, 
                          -params_.integral_limit, params_.integral_limit);
    
    double output = params_.kv * vel_error + params_.ki_v * vel_integral_;
    return clamp(output, -params_.output_limit, params_.output_limit);
  }
  
  void Reset() {
    vel_integral_ = 0.0;
  }
  
 private:
  Params params_;
  double vel_integral_ = 0.0;
};
```

#### 4.5.3 速度估计（若底层无速度反馈）

```cpp
// 速度观测器（若编码器只提供位置）
class VelocityObserver {
 public:
  double Estimate(double q_meas, double dt) {
    // 一阶低通滤波的微分
    double raw_vel = (q_meas - q_last_) / dt;
    q_last_ = q_meas;
    
    // 低通滤波：alpha = dt / (tau + dt), tau 为滤波时间常数
    double alpha = dt / (tau_ + dt);
    vel_est_ = alpha * raw_vel + (1.0 - alpha) * vel_est_;
    
    return vel_est_;
  }
  
 private:
  double q_last_ = 0.0;
  double vel_est_ = 0.0;
  double tau_ = 0.05;  // 50ms 滤波时间常数
};
```

### 4.6 参数整定步骤

**步骤 1：整定速度内环（先内后外）**
```
1. 断开位置外环，直接给速度指令
2. 阶跃响应测试：v_cmd = 10°/s
3. 调整 Kv 直到响应快速无振荡
4. 加入 Ki_v 消除稳态误差
```

**步骤 2：整定位置外环**
```
1. 闭合位置环
2. 位置阶跃测试：Δq = 10°
3. 调整 Kp_pos 直到响应平稳
4. 验证速度限幅 v_max 足够
```

**步骤 3：验证段切换**
```
1. 模拟段切换场景
2. 观察速度指令是否平滑
3. 验证控制量无突变
```

### 4.7 推荐参数

| 参数 | 推荐值 | 说明 |
|:---|:---|:---|
| Kp_pos | 1.5-3.0 (1/s) | 位置环带宽约 0.5-1 Hz |
| v_max | 15-25 (°/s) | 略大于规划最大速度 |
| Kv | 5-15 | 速度环带宽约 5-10 Hz |
| Ki_v | 1-5 | 消除稳态误差 |
| 速度滤波 τ | 30-100 ms | 平衡噪声与延迟 |

## 5. 方案对比总结

### 5.1 综合评分

| 指标 | 纯位置环 | 纯速度环 | 串级控制 |
|:---|:---:|:---:|:---:|
| 位置精度 | ★★★★★ | ★★ | ★★★★★ |
| 速度平滑 | ★★★ | ★★★★ | ★★★★★ |
| 抗负载扰动 | ★★ | ★★★ | ★★★★★ |
| 段切换鲁棒性 | ★★ | ★★★★ | ★★★★ |
| 实现复杂度 | ★★★★★ | ★★★ | ★★ |
| 参数整定难度 | ★★★★ | ★★★ | ★★ |
| **综合推荐** | **★★★** | **★★** | **★★★★★** |

### 5.2 适用场景

| 方案 | 适用场景 |
|:---|:---|
| 纯位置环 | 简单应用、精度要求高、无速度反馈 |
| 纯速度环 | 速度控制为主、位置精度要求低 |
| 串级控制 | 高精度轨迹跟踪、液压系统、段间平滑要求高 |

### 5.3 选型建议

```
if (有速度反馈 && 可改控制层) {
    选择：串级控制（最优）
} else if (只能改规划层) {
    选择：纯位置环 + 段起点限幅
} else if (位置精度要求低) {
    选择：纯速度环 + 位置校准
}
```
