## 一页看懂：本案要保护什么

> **① 保护什么（一句话）**：不保护"看料面选卸载点"的想法（该想法已被公开），
> 只保护**挖掘机每斗自主决定卸在哪的组合机制**——
> **点云双重门限判满 · 逐点逆运动学可达性筛选 · 自远及近遍历 · 斗数双向保底**（斗数不足时"不相信"传感器的全满结论）。
>
> **② 为什么值钱（一句话）**：靠这套机制，**矿卡停偏、点云遮挡、传感器失效**三类恶劣工况下，
> 装车都能**在保底斗数区间内必然完成**——不误停拉半车、不失灵装超载、选出的点永远可卸。

| # | 保护点 | 一句话 | 强度 |
|:---:|:---|:---|:---:|
| ① | 候选点远密近疏分布 | 支撑特征（服务于②④） | 弱 |
| **②** | **逐点 IK 确定可达域边界** | 选出的点**必然可达** | **强** |
| **③** | **点云双重门限判满** | 点数门限 + 平均高度门限，**点数不足判未满** | **强** |
| **④** | **自远及近遍历取首个未满点** | 布料顺序写死为必要特征 | 中 |
| **⑤** | **斗数双向保底** | **全满但斗数不足时"不相信"感知结论** | **最强** |

**核心主张**：②③④⑤ 已固化为独立权利要求 1 的**必要技术特征**，四者互为因果、不可拆分。

## 1. 现场问题：自动装车“选点”到底难在哪

**四个必须回答的工程问题**

```
   点选在哪里？  →  能不能到？  →  那儿满没满？  →  什么时候停？
        ①              ②               ③               ⑤
```

**三类现场故障（本方案的直接来由）**

| 故障 | 现场表现 | 根因 |
|:---|:---|:---|
| 装车失败 | 矿卡停偏 0.5~1.0 m，目标点超出工作半径 | 选点**不校验运动学可达性** |
| 撒料 / 铲斗撞料堆 | 反复卸向同一处，料堆越过厢沿 | 选点**不感知"哪里已满"** |
| 半车运输 / 超载 | 一次误判即终止；或感知失灵持续超装 | **单一感知源**决定装载终止 |

> 装车环节直接决定单班产量与运输成本——选点是无人矿山产能链上的**决策咽喉**。

## 5. 技术方案总览（七步）

```
 步骤1 候选点生成          厢中心线 N 点，远密近疏，按 RTK 位姿变换
   ↓
 步骤2 逐点 IK 筛选   ★②   主解 + 固定斗角保底解 + 限位安全余量 → 可达域边界
   ↓
 步骤3 矿卡可达性判定      最远可达索引 vs 0.5N（含"已装满豁免"）
   ↓
 步骤4 双重门限判满   ★③   点数门限 + 局部平均高度门限 + 满载状态跨轮继承
   ↓  （点云不可用 → 步骤4′ 装载次数三段式映射：远/中/近）
   ↓
 步骤5 由远及近遍历   ★④   取第一个"未满"的可达点
   ↓
 步骤6 斗数双向保底   ★⑤   上限强制终止 / 下限不采信全满 / 中位点兜底
   ↓

```

**三类信息源彼此独立**：几何运动学（②）· 感知（③）· 计数（⑤）→ 互为冗余、交叉校验。

## 6. 保护点 ②：逐点 IK 确定可达域边界　【强】

### 保护什么
对**每一个**候选点求解逆运动学，按**带安全余量的关节限位**校验，得到可达点集合与**可达域边界（最远可达索引）**。

- 主解：给定铲斗姿态角解 [回转, 动臂, 斗杆, 铲斗]
- 保底解：主解失败 → 固定铲斗关节角（25°~30°）联合逆解**重试**
- 限位余量：优选 2°；回转角统一 `swing = (atan2d(y,x)+180) mod 360`

### 为什么不可替代
| F-1 / CN-1 | 本案 |
|:---|:---|
| 卸载点由**料面几何**决定，未见公开运动学可解性筛选 | 选出的点**必然可达**，停偏时自动在缩小后的可达域内选点 |

> **18 篇检索文献中，无一篇以逆运动学可解性筛选卸载点。**

---

## 7. 保护点 ③：点云双重门限判满　【强】

### 保护什么（三要素，缺一不可）
1. 区域点数 **>** 点数门限 → 计算区域点云**平均高度**；
2. 平均高度 ≤ 车厢框沿高 + 余量 → 判**未满**，否则判**已满**；
3. 区域点数 **≤** 点数门限 → **直接判"未满"（保守取向）**。

### 为什么不是"设两个阈值"这么简单
| 误判类型 | 场景 | 拦截手段 |
|:---|:---|:---|
| **稀疏误判** | 遮挡、扬尘、视角不佳 → 点少高度失真 | 点数门限 + **保守判未满** |
| **尖峰误判** | 飞石、噪点、料堆尖 → 最高点虚高 | 用**平均高度**而非最高点 |

**两道门限方向相反地各挡一类误判**，误判方向恒偏安全（宁可多卸一斗，不误停）。

> 与国内 CN-1 的**深度直方图**是两条不同算法路线——撰写时刻意避开"直方图/高度分布统计"措辞。

---

## 8. 保护点 ④：自远及近遍历取首个未满点　【中】

### 保护什么
自可达域**最远可达点**向**最近可达点**方向逐点遍历，取**第一个**判定为未满的点作为当前卸载点，并输出其关节角。

### 与 ① 的因果闭环（不是两个独立特征）

```
   ① 远端密集、近端稀疏          ④ 由远及近遍历
   t = 1-(1-t_raw)^k, k=2.5   ←→  首轮布料落在可达域边界附近
            ↓                            ↓
   远端是最先使用、也最先触及可达域边界的区域
            ↓
   → 远端加密 = 边界判定分辨率最高 = 车厢装载空间利用最大化
```

### 技术效果
由远及近均匀布料，**防近端先堆高阻挡远端**、防铲斗越料撞料堆。

> F-1 / NPL-1 均未见公开明确的布料顺序与遍历方向。

---

## 9. 保护点 ⑤：斗数双向保底　【★最强·全案创造性支点】

### 保护什么（双向，不是单向限幅）

| 方向 | 触发条件 | 动作 | 防的事故 |
|:---|:---|:---|:---|
| 上限 | 累计斗数 **>** 上限阈值 | 强制结束本车，取**中位可达点**补最后一斗 | 感知失灵导致**超载** |
| **下限** | 全部可达点判"已满" **但** 斗数 **≤** 下限阈值 | **不采信该"全满"结论**，取中位可达点**继续装载** | 误判导致**半车运输** |
| 兜底 | 任一异常退出路径 | 输出中位可达点及其关节角 | **系统永不无解** |

### 为什么非显而易见（答辩要点）
- 上限限幅属常规；**下限"不相信感知结论"是反向逻辑**——与"感知驱动选点"的技术方向**相冲突**；
- F-1 / CN-1 均以**单一感知源**决定装载终止，**不存在**质疑感知结论可信性的技术启示，因而**无结合动机**；
- 带来 F-1 无法取得的效果：**单传感器失效不中断作业**。

> **18 篇文献 + 2 篇 NPL 中，无任何近似公开。**

## 10. 多机制联动主线：四点互为因果（回应“单一创新点偏弱”）

> **回应评审建议②-c**：创造性**不在“按装载进度动态调整卸载点”这一上位思想**（与 CN109902857B / CN114164877B 重合），而在下述**三源因果闭环 + 计数对感知的反向否决**。

**形式化命题**：可达域 `R`（IK 筛选）、未满域 `U`（点云双门限）、计数约束 `C`（斗数双向保底），则 `p* = argfirst_{i∈R, 由远及近}(i∈U)`（选点 = 可达域 ∩ 未满域、按布料方向取首个），再经 `C` 修正——`U=∅ 且斗数≤下限`时**否决“满”结论**（防误停）、`斗数>上限`时**强制终止**（防超载）。三源**彼此独立、交叉校验、相互否决**，这是区别于“单一感知源判满即终止”现有技术的实质特征。

```
        ①  候选点远密近疏
             │  提供离散决策空间与边界分辨率
             ▼
    ★②  逐点 IK → 可达域边界 ──────────┐
             │  提供"最远可达点"这个遍历起点   │
             ▼                              │ 提供"中位可达点"
    ★③  双重门限判满（点级）              │ 这个兜底目标
             │  提供"未满/已满"这个遍历判据    │
             ▼                              │
    ★④  自远及近取首个未满点 ◄────────────┘
             │  提供"全部判满"这个触发信号
             ▼
    ★⑤  斗数双向保底（反向校验 ③ 的结论）
```

**审查/无效视角**：需同时找到覆盖 ②③④⑤ 的文献，或论证四者的结合动机——
而 ⑤ 是对 ③ 的**反向否定**，感知驱动路线内部**不产生**这种动机。

**竞品视角**：做自动装车必须回答“点在哪 / 能不能到 / 满没满 / 何时停”四问，
本案对四问各给一个具体解法且**互为输入输出**，单独替换任一环都会破坏闭环。

## 10B. 机制细化②：主流程判断分支 + 判定表（回应建议①·流程图）

## 11. 独立权利要求 1（收窄版·拟提交 L1 层级）

一种基于装载进度的挖掘机卸载点动态选取方法，包括：

**①** 在矿卡车厢坐标系内沿车厢中心线生成 N 个候选卸载点，所述候选点沿中心线呈**远端密集、近端稀疏**的非线性分布，并按矿卡实测位姿变换至挖掘机坐标系；

**②** 对所述候选点**逐一求解**挖掘机**逆运动学**，并按**带安全余量的关节限位**进行校验，得到可达候选点集合及**可达域边界**；

**③** 对可达候选点，以该点为中心的预设区域内的料面点云进行装载完成状态判定；区域内点云点数**大于**点数门限时，计算区域内点云的**平均高度**，平均高度不大于车厢框沿高度与预设余量之和则判**未满**、否则判**已满**；区域内点云点数**不大于**点数门限时判**未满**；

**④** 自可达候选点集合中的**最远可达点向最近可达点方向遍历**，取**第一个**判定为未满的可达候选点作为当前卸载点，并输出其对应关节角；

**⑤** 累计装载斗数**大于上限阈值**时强制结束本车装载并取**中位可达点**执行最后一斗；全部可达候选点均判定为已满但累计装载斗数**不大于下限阈值**时，**不采信该已满判定**，取中位可达点继续装载。

**另设**：独 12（系统·七模块）、独 13（计算机可读存储介质）

## 14. 创造性论证（三步法）

**第一步 · 最接近现有技术**：F-1（US6363632B1）及其同源 NPL-1

**第二步 · 区别技术特征**：②可达域约束　③双重门限具体判据　④自远及近遍历　⑤斗数双向保底

**第三步 · 是否显而易见**

| 视角 | 论证 |
|:---|:---|
| 单篇 | F-1/NPL-1 是"**料面几何 → 卸载点**"单链条，其中**不存在**运动学可达性维度，也**不存在**对感知结论可信性的质疑 → 不含改进启示 |
| 结合 | 即便引入 CN-1 作对比文件 2，其仍属**同一链条内的算法替换**，无法提供"**不采信全满结论并继续装载**"的动机 |
| 反向教导 | ⑤ 在技术方向上与"感知驱动"**相冲突**，属反向教导下的设计 |
| 技术效果 | 取得 F-1 无法取得的效果：**单传感器失效不中断作业**、**选点必然可达**、**误判方向恒偏安全** |

**结论**：②③④⑤ 的组合非显而易见。
