背景技术（现有专利的缺点）

挖掘机自动装车中"卸载点选在哪里"，现有技术主要有六类做法：固定点位、人工指定、料位/满斗率检测辅助、轨迹约束点、感知驱动卸载点序列规划（US6363632B1、CN109902857B）、网格覆盖式预规划（CN114164877B）。其中最接近的现有专利 CN109902857B 以单激光雷达点云深度直方图表征车厢凹凸并"寻找合适的卸载点"，按额定载荷百分比阈值切换装满/重心两阶段优先、并在铲斗安全卸载范围内选点。但上述做法存在以下缺点：

  1. 选点与可达域脱节：CN109902857B 仅有基于铲斗宽度比例的几何安全范围，CN114164877B 的逆运动学仅用于执行到位，卡车停偏时选点仍可能不可达；
  2. 判满判据缺失或单一：深度直方图/整车总重均无"某候选点是否已满"的点级判据，点云稀疏或尖峰噪点易误判；
  3. 单一感知源定终止：一次误判即提前终止或持续超装，无计数交叉校验；
  4. 布料顺序非闭环：预规划顺序重复或按整车载荷百分比切换原则，易近端堆高、铲斗越料；
  5. 与执行层脱节：选点结果不直接衔接卸载轨迹。

技术方案（三源联动 · 创造性主线）

        可达域(几何/运动学)      料面状态(感知)        装载斗数(计数)
              │ 逐点IK筛         │ 双门限判满          │ 双向保底
              ▼                  ▼                    ▼
          [可达候选点]  ∩  [判定未满点]  →  自远及近取首个  →  卸载点
              │                  │                    │
              └──── 三类信息源彼此独立、互为冗余、交叉校验 ────┘
   下限保底：全部判"已满" 但 斗数≤下限 → 不采信该结论，取中位可达点继续
回应建议②-c（单一创新点偏弱）：创造性不在"按装载进度动态调整卸载点"这一上位思想（与 CN109902857B/CN114164877B 重合），而在下述三源因果闭环 + 计数对感知的反向否决。

形式化命题：设可达域 R（IK 筛选）、未满域 U（点云双门限）、计数约束 C（斗数双向保底），则 p* = argfirst_{i∈R, 由远及近}(i∈U)，再经 C 修正——U=∅ 且斗数≤下限时否决"满"结论（防误停）、斗数>上限时强制终止（防超载）。三源独立、交叉校验、相互否决，区别于"单一感知源判满即终止"的现有技术。

本发明的优点

  1. 选出的卸载点必然可达，卡车停靠偏差自适应，停偏时在缩小后的可达域内自动选点；
  2. 布料与实际料面闭环，车厢由远及近均匀装满，避免局部堆高、撒料与铲斗越料；
  3. 双重门限拦截稀疏与尖峰两类典型误判，判满结论稳定、不抖动；
  4. 感知与计数互为冗余，单传感器失效不中断作业，杜绝误停半车与感知失灵超载；
  5. 系统永不无解，任何异常均输出中位可达点兜底，且选点与卸载轨迹一体化衔接。

关键点和保护点（领导最关注点）

需要保护的技术创新点为以下互为因果、不可拆分的组合机制（独立权利要求 1 必要技术特征）：

  1. 车厢中心线 N 点远密近疏候选点生成＋按矿卡实测位姿变换；
  2. 逐候选点逆运动学可解性筛选并据此确定可达域边界；
  3. 点级双重门限判满（点数门限＋局部平均高度门限＋点数不足保守判未满）；
  4. 自最远可达点向近端遍历取首个未满点；
  5. 斗数双向保底——全满但斗数不足时不采信感知结论、取中位可达点继续（全案创造性支点）。

不保护"感知料面→选卸载点"的上位思想（该思想已被 CN109902857B / US6363632B1 公开）。创造性主线为 ②③④⑤ 的三源联动 + 计数对感知反向否决（见「三源联动」页）。
