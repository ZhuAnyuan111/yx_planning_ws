## 背景技术

**对现有技术情况的介绍（可结合附图说明，现有专利的缺点）：**

挖掘机自动装车中"卸载点选在哪里"，现有技术主要有六类做法：固定点位、人工指定、料位/满斗率检测辅助、轨迹约束点、**感知驱动卸载点序列规划**（US6363632B1、CN109902857B）、**网格覆盖式预规划**（CN114164877B）。其中最接近的现有专利 **CN109902857B** 以单激光雷达点云**深度直方图**表征车厢凹凸并"寻找合适的卸载点"，按额定载荷百分比阈值切换**装满/重心两阶段优先**、并在铲斗**安全卸载范围**内选点（表 1）。但上述做法存在以下缺点（表 2）：

1）**选点与可达域脱节**：CN109902857B 仅有基于铲斗宽度比例的几何安全范围，CN114164877B 的逆运动学仅用于执行到位，卡车停偏时选点仍可能不可达；
2）**判满判据缺失或单一**：深度直方图/整车总重均无"某候选点是否已满"的点级判据，点云稀疏或尖峰噪点易误判；
3）**单一感知源定终止**：一次误判即提前终止或持续超装，无计数交叉校验；
4）**布料顺序非闭环**：预规划顺序重复或按整车载荷百分比切换原则，易近端堆高、铲斗越料；
5）**与执行层脱节**：选点结果不直接衔接卸载轨迹。

## 本发明提出的技术方案

以"**可达域 ∩ 未满域**驱动动态选点、并以**斗数双向保底**兜底"为本方案的基本策略。具体是通过在车厢中心线生成远密近疏候选点、逐点逆运动学筛选定可达域边界、点云双重门限判满、自远及近遍历取首个未满点、斗数双向保底校验的七步闭环（图 1）。

```
 步骤1 候选点生成        厢中心线 N 点(优选21)，远密近疏 t=1-(1-t)^k，按 RTK 位姿变换
   ↓
 步骤2 逐点 IK 筛选  ★   主解+固定斗角保底解+限位余量(2°) → 可达域边界(最远可达索引)
   ↓
 步骤3 矿卡可达性判定     最远可达索引 vs 0.5N（含"阈值位已装满豁免"）
   ↓
 步骤4 双重门限判满  ★   点数门限 + 局部平均高度门限 + 满载状态跨轮继承
   ↓ （点云不可用 → 步骤4′ 装载次数三段式映射：远/中/近）
 步骤5 由远及近遍历  ★   取第一个"未满"的可达点
   ↓
 步骤6 斗数双向保底  ★   上限强制终止 / 下限不采信全满 / 中位点兜底
   ↓
 步骤7 调度与轨迹衔接     回转圆 ∩ 车厢矩形 → 入厢衔接点
```

## 本发明提出的技术方案

```
        可达域(几何/运动学)      料面状态(感知)        装载斗数(计数)
              │ 逐点IK筛         │ 双门限判满          │ 双向保底
              ▼                  ▼                    ▼
          [可达候选点]  ∩  [判定未满点]  →  自远及近取首个  →  卸载点
              │                  │                    │
              └──── 三类信息源彼此独立、互为冗余、交叉校验 ────┘
   下限保底：全部判"已满" 但 斗数≤下限 → 不采信该结论，取中位可达点继续
```

1、当点云不可用/遮挡/无效时，退化为**装载次数三段式映射**（最远/中位/最近可达点，T1=3、T2=6、T3=9），保证降级工况仍可作业，系统永不无解；

2、本方案可扩展应用到装载机、电铲装卡车等凡存在可达域约束与布料需求的场景；选点结果同时输出**回转圆入厢衔接点**，直接驱动下游卸载轨迹航路点，无需中间转换。

## 本发明的优点

1、选出的卸载点**必然可达**，卡车停靠偏差自适应，停偏时在缩小后的可达域内自动选点；

2、布料与实际料面**闭环**，车厢由远及近均匀装满，避免局部堆高、撒料与铲斗越料；

3、**双重门限**拦截稀疏与尖峰两类典型误判，判满结论稳定、不抖动；

4、感知与计数**互为冗余**，单传感器失效不中断作业，杜绝误停半车与感知失灵超载；

5、系统**永不无解**，任何异常均输出中位可达点兜底，且选点与卸载轨迹一体化衔接。

## 关键点和保护点（领导最关注点）

需要保护的技术创新点为以下**互为因果、不可拆分**的组合机制（独立权利要求 1 必要技术特征）：

**①** 车厢中心线 N 点**远密近疏**候选点生成＋按矿卡实测位姿变换；
**②** 逐候选点**逆运动学可解性筛选**并据此确定**可达域边界**；
**③** **点级双重门限判满**（点数门限＋局部平均高度门限＋点数不足保守判未满）；
**④** **自最远可达点向近端遍历**取首个未满点；
**⑤** **斗数双向保底**——全满但斗数不足时**不采信感知结论**、取中位可达点继续（全案创造性支点）。

**不保护**"感知料面→选卸载点"的上位思想（该思想已被 CN109902857B / US6363632B1 公开）。
