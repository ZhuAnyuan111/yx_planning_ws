## 编译与运行

```bash
# 编译（含测试目标）
cd ~/yx_planning_ws
source /opt/ros/noetic/setup.bash
catkin_make --pkg dump_trajectory_planner -DCATKIN_ENABLE_TESTING=ON
cd build && make -j$(nproc) tests

# 运行全部测试
catkin_make run_tests_dump_trajectory_planner

# 或直接运行单个测试二进制
source devel/setup.bash
./devel/lib/dump_trajectory_planner/test_angle_utils
./devel/lib/dump_trajectory_planner/test_cubic_hermite_interpolator
./devel/lib/dump_trajectory_planner/test_velocity_estimator
./devel/lib/dump_trajectory_planner/test_waypoint_generator

# 按名称过滤运行
./devel/lib/dump_trajectory_planner/test_cubic_hermite_interpolator --gtest_filter=*Overshoot*
```

部署时可跳过测试编译：
```bash
catkin_make -DCATKIN_ENABLE_TESTING=OFF --pkg dump_trajectory_planner
```

## 测试覆盖的核心安全特性

| 安全特性 | 对应用例 | 验证结论 |
|---------|---------|---------|
| PCHIP 无超调 | NoOvershoot_LargeStartTangent / LargeEndTangent / OpositeTangent | 极端切线输入仍不超出起终范围 |
| Swing 跨零安全 | SwingWrap_CrossZero / NoPseudoLargeValue | 不产生 ±350° 伪速度 |
| 速度限幅 | Clamping_LargeVelocity / NegativeVelocity | 噪声不传播到 PCHIP 切线 |
| 终点锚定 | WP6_EqualsUnloadJoint | 卸载终点不漂移 |
| Seg1 boom 不下降 | WP5_BoomEqualsWP4 | 回转期间不会压向料堆 |
| 航路点展开 | SwingUnwrap_AdjacentDiffLe180 / UnwrapSwing_AcrossZero | 回转方向不因 0°/360° 翻转 |
| 包络预筛 | EnvelopePrefilter_TooClose / TooFar / TooHigh | 超范围点不进入 IK |
